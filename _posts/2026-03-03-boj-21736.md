## 문제 링크
[https://www.acmicpc.net/problem/21736](https://www.acmicpc.net/problem/21736)

## 문제 설명
N×M 크기의 캠퍼스에서 도연이의 위치가 'I'로 주어진다.
캠퍼스는 다음 문자로 구성된다.

- 'O' : 빈 공간
- 'X' : 벽(이동 불가)
- 'P' : 사람
- 'I' : 도연이의 시작 위치

도연이가 상하좌우로 이동할 수 있을 때, 만날 수 있는 사람('P')의 수를 출력한다.
만날 수 있는 사람이 없으면 "TT"를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 시작 지점에서 이동 가능한 모든 칸을 탐색하며 'P'의 개수를 세는 **그래프 탐색(BFS/DFS)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`visited[y][x]`를 (y, x) 칸을 방문했는지 여부라고 정의하면,

- 시작점 'I'에서 BFS를 시작한다.
- 벽('X')은 통과할 수 없으므로 큐에 넣지 않는다.
- BFS로 도달 가능한 모든 칸을 방문하면서, 사람이 있는 칸('P')을 만나면 카운트를 증가시킨다.
- BFS가 끝나면 카운트가 0인지 여부에 따라 출력 형식이 달라진다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

struct Point
{
    int y, x;
};

int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

int n, m;
int ans;
vector<vector<char>> campus;
vector<vector<char>> visited;
Point st;

void init()
{
    cin >> n >> m;
    campus.assign(n, vector<char>(m, 0));
    visited.assign(n, vector<char>(m, 0));
    ans = 0;

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> campus[i][j];
            if (campus[i][j] == 'I')
                st = { i,j };
        }
    }
}

void bfs()
{
    queue<Point> q;
    q.push(st);
    visited[st.y][st.x] = 1;

    while (!q.empty())
    {
        Point cp = q.front();
        q.pop();
        for (int i = 0; i < 4; i++)
        {
            Point np = { cp.y + dy[i], cp.x + dx[i] };
            if (np.y < 0 || np.x < 0 || np.y >= n || np.x >= m)
                continue;
            if (visited[np.y][np.x] == 1)
                continue;
            if (campus[np.y][np.x] == 'X')
                continue;

            if (campus[np.y][np.x] == 'P')
                ans++;

            q.push(np);
            visited[np.y][np.x] = 1;
        }
    }
}

void solve()
{
    init();
    bfs();
    if (ans == 0)
        cout << "TT";
    else
        cout << ans;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times M)$$
BFS는 각 칸을 최대 한 번 방문하고,
각 방문에서 4방향만 확인하므로 전체 연산량은 칸 수에 비례합니다.
따라서 시간복잡도는 $$O(NM)$$ 입니다.

### 2. 공간복잡도 : $$O(N \times M)$$
지도 `campus`와 방문 배열 `visited`가 각각 $$O(NM)$$ 공간을 사용합니다.
BFS 큐도 최악의 경우 $$O(NM)$$까지 커질 수 있으므로 전체 공간복잡도는 $$O(NM)$$ 입니다.
