## 문제 링크
[https://www.acmicpc.net/problem/2630](https://www.acmicpc.net/problem/2630)

## 문제 설명
N×N 크기의 종이가 주어지고, 각 칸은 흰색(0) 또는 파란색(1)으로 칠해져 있다.
이 종이를 같은 색으로만 칠해진 정사각형들로 분할하려고 한다.

- 모두 0이면 흰색 색종이 1개
- 모두 1이면 파란색 색종이 1개
- 섞여 있으면 4등분하여 같은 과정을 반복

최종적으로 만들어지는 흰색/파란색 색종이의 개수를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 종이를 4등분하면서 “현재 구간이 단색인지”를 확인하는 **분할정복(재귀)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
현재 정사각형의 왼쪽 위 좌표를 (y, x), 한 변의 길이를 size라고 하면,

- (y, x)부터 size×size 구간이 전부 0이면 흰색 개수(whiteCnt)를 1 증가시키고 종료한다.
- 전부 1이면 파란색 개수(blueCnt)를 1 증가시키고 종료한다.
- 0과 1이 섞여 있으면 size/2로 4등분하여 같은 과정을 재귀적으로 반복한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

vector<vector<int>> map;
int n, whiteCnt, blueCnt;

void init()
{
    cin >> n;
    map.assign(n, vector<int>(n, 0));
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            cin >> map[i][j];
        }
    }
}

void dfs(int y, int x, int size)
{
    bool zero = true, one = true;
    for (int i = y; i < y + size; i++)
    {
        for (int j = x; j < x + size; j++)
        {
            if (map[i][j] == 1)
                zero = false;
            if (map[i][j] == 0)
                one = false;
        }
    }

    if (zero)
    {
        whiteCnt++;
        return;
    }
    if (one)
    {
        blueCnt++;
        return;
    }

    dfs(y, x, size / 2);
    dfs(y, x + size / 2, size / 2);
    dfs(y + size / 2, x, size / 2);
    dfs(y + size / 2, x + size / 2, size / 2);
}

void solve()
{
    init();
    dfs(0, 0, n);
    cout << whiteCnt << "\n" << blueCnt;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N^2 \log N)$$ (최악)
각 재귀 호출에서 size×size 영역을 한 번 훑으며 단색인지 확인합니다.
최악의 경우 끝까지 계속 4등분되면,
레벨 0에서는 $$N^2$$, 레벨 1에서는 4개 구간을 각각 $$ (N/2)^2 $$ 검사하므로 합이 $$N^2$$,
이런 식으로 레벨마다 총 검사량이 $$N^2$$가 되고 레벨 수가 $$\log N$$ 이므로
최악 시간은 $$O(N^2 \log N)$$ 입니다.

### 2. 공간복잡도 : $$O(N^2)$$
입력 배열 `map`이 $$O(N^2)$$ 공간을 사용합니다.
재귀 깊이는 최대 $$\log N$$ 이므로 호출 스택은 추가로 $$O(\log N)$$ 이지만,
전체는 $$O(N^2)$$가 지배적입니다.
