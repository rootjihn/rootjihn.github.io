## 문제 링크
[https://www.acmicpc.net/problem/30804](https://www.acmicpc.net/problem/30804)

## 문제 설명
길이가 N인 과일 배열이 주어진다. 과일은 번호(1~9)로 표현된다.
연속한 구간을 선택했을 때, 그 구간 안에 들어있는 과일의 종류가 최대 2개가 되도록 하면서
선택할 수 있는 연속 구간의 최대 길이를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “연속 구간”에서 “종류 수가 2개 이하”라는 조건을 유지하며 최댓값을 구하는 문제이므로
**투 포인터(슬라이딩 윈도우)** 로 해결하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- `left`, `right`를 윈도우(구간)의 양 끝 인덱스로 둔다.
- `cnt[x]`를 현재 윈도우 안에 과일 x가 몇 개 있는지로 정의한다.
- `kinds`를 현재 윈도우 안에 존재하는 과일 종류 개수로 정의한다.

동작 방식
- `right`를 0부터 N-1까지 늘리며 과일을 윈도우에 포함한다.
- 새로 들어온 과일 x가 처음 등장한 종류라면 `kinds++` 한다.
- `kinds > 2`가 되면 조건을 만족할 때까지 `left`를 증가시키며 윈도우를 줄인다.
  - 빠지는 과일 y의 개수를 감소시키고, 0이 되면 그 종류는 윈도우에서 사라진 것이므로 `kinds--` 한다.
- 매 단계마다 조건(kinds ≤ 2)을 만족하는 상태에서 `right - left + 1`로 윈도우 길이를 갱신한다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int n;
vector<int> tang;

void init() {
    cin >> n;
    tang.assign(n, 0);
    for (int i = 0; i < n; i++) cin >> tang[i];
}

void solve() {
    int cnt[10] = { 0 };
    int kinds = 0;
    int ans = 0;

    int left = 0;
    for (int right = 0; right < n; right++) {
        int x = tang[right];
        if (cnt[x] == 0) kinds++;
        cnt[x]++;

        while (kinds > 2) {
            int y = tang[left];
            cnt[y]--;
            if (cnt[y] == 0) kinds--;
            left++;
        }

        ans = max(ans, right - left + 1);
    }

    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N)$$
`right`는 0부터 N-1까지 한 번씩 증가하고,
`left`도 전체 과정에서 최대 N번만 증가합니다(각 원소는 윈도우에 들어가고 나오는 과정이 각각 한 번).
따라서 전체 시간복잡도는 $$O(N)$$ 입니다.

### 2. 공간복잡도 : $$O(1)$$
과일 번호 범위가 1~9로 고정이므로 `cnt[10]`은 상수 크기입니다.
추가로 사용하는 변수들도 상수 개수이므로 공간복잡도는 $$O(1)$$ 입니다.
