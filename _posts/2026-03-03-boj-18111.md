## 문제 링크
[https://www.acmicpc.net/problem/18111](https://www.acmicpc.net/problem/18111)

## 문제 설명
N×M 크기의 땅 높이가 주어지고, 인벤토리에 블록 B개가 있다.
모든 칸의 높이를 같은 높이 H로 맞추려고 할 때 걸리는 최소 시간을 구한다.

- 높이를 1 줄여 블록을 제거하면 2초가 걸리고, 제거한 블록은 인벤토리에 추가된다.
- 높이를 1 올려 블록을 추가하면 1초가 걸리고, 인벤토리에서 블록을 사용한다.
- 목표: 최소 시간, 시간이 같다면 목표 높이 H가 더 큰 것을 선택

---

## 풀이 전략 (Approach)
이 문제는 가능한 목표 높이 H를 전부 시도해보고, 각 H에서 필요한 시간과 가능 여부를 계산하는 **완전탐색(브루트포스) + 시뮬레이션** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
목표 높이를 H라고 할 때, 각 칸의 현재 높이를 cur라 하면,

- cur > H 이면 (cur - H)만큼 블록을 제거해야 하고, 제거한 블록은 인벤토리에 들어간다.
  - 제거 블록 수 합: `sum_sub`
- cur < H 이면 (H - cur)만큼 블록을 추가해야 하고, 인벤토리에서 사용한다.
  - 추가 블록 수 합: `sum_add`

가능 조건
- 추가해야 하는 블록 `sum_add`는 인벤토리에 있는 블록 B와 제거해서 얻는 블록 `sum_sub`의 합보다 클 수 없다.

$$
sum\_add \le B + sum\_sub
$$

시간 계산
- 제거는 블록 1개당 2초, 추가는 1개당 1초이므로

$$
time(H) = 2 \cdot sum\_sub + 1 \cdot sum\_add
$$

모든 H(minH ~ maxH)를 돌면서
- 가능한 경우만 계산하고
- 시간이 최소인 H를 선택
- 시간이 같으면 더 큰 H를 선택한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <climits>
#include <algorithm>

using namespace std;

int n, m, b;
int maxH, minH;
vector<vector<int>> worlds;

long long sum_add;
long long sum_sub;
long long bestTime;
int bestH;

void init()
{
    cin >> n >> m >> b;
    worlds.assign(n, vector<int>(m, 0));

    maxH = INT_MIN;
    minH = INT_MAX;

    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < m; ++j)
        {
            cin >> worlds[i][j];
            maxH = max(maxH, worlds[i][j]);
            minH = min(minH, worlds[i][j]);
        }
    }
}

void cnt_block(int h)
{
    sum_add = 0;
    sum_sub = 0;

    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < m; ++j)
        {
            int cur = worlds[i][j];
            if (cur > h)
                sum_sub += (cur - h);
            else
                sum_add += (h - cur);
        }
    }
}

void solve()
{
    init();

    bestTime = LLONG_MAX;
    bestH = INT_MIN;

    for (int h = minH; h <= maxH; ++h)
    {
        cnt_block(h);

        if (sum_add > (long long)b + sum_sub)
            continue;

        long long time = sum_sub * 2 + sum_add;

        if (time < bestTime || (time == bestTime && h > bestH))
        {
            bestTime = time;
            bestH = h;
        }
    }

    cout << bestTime << " " << bestH;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O((maxH - minH + 1) \times N \times M)$$
목표 높이 H를 minH부터 maxH까지 모두 시도하고,
각 H마다 전체 격자 N×M을 한 번 순회하며 필요한 블록 수를 계산합니다.
따라서 전체 시간복잡도는 $$O((maxH-minH+1)\cdot NM)$$ 입니다.
(문제의 높이 범위가 0~256이라서 충분히 빠르게 동작합니다.)

### 2. 공간복잡도 : $$O(N \times M)$$
입력 격자 `worlds`를 저장하는 데 $$O(NM)$$ 공간이 필요합니다.
추가 변수들은 상수 공간이므로 전체 공간복잡도는 $$O(NM)$$ 입니다.
