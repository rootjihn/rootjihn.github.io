## 문제 링크
[https://www.acmicpc.net/problem/16928](https://www.acmicpc.net/problem/16928)

## 문제 설명
1부터 100까지 번호가 붙은 칸이 있는 보드에서 1번 칸에서 시작한다.
주사위를 굴려 1~6만큼 이동할 수 있고, 도착한 칸에 사다리/뱀이 있으면 지정된 칸으로 즉시 이동한다.

- 사다리: 올라감
- 뱀: 내려감

100번 칸에 도착하기 위한 주사위 굴림 횟수의 최솟값을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 각 칸을 정점으로 보고, 주사위(1~6) 이동을 간선으로 보는 **최단 거리 문제**입니다.
모든 이동의 비용이 1(주사위 1회)로 동일하므로 **BFS**로 최솟값을 구할 수 있습니다.

### 1. 상태 정의 및 알고리즘 도출
- `moveTo[x]` : 칸 x에 사다리/뱀이 있으면 도착해야 하는 칸, 없으면 0
- `dist[x]` : 1번에서 x번 칸까지 도달하는 데 필요한 최소 주사위 횟수(미방문은 -1)

동작 방식
- 1번 칸에서 BFS 시작, `dist[1]=0`
- 현재 칸 cur에서 주사위를 1~6 굴려 다음 칸 nx = cur + dice 를 만든다.
- nx가 100을 넘으면 무시한다.
- nx에 사다리/뱀이 있으면 `nx = moveTo[nx]`로 즉시 이동한다.
- 아직 방문하지 않은 칸이면 `dist[nx] = dist[cur] + 1`로 갱신하고 큐에 넣는다.
- BFS가 끝나면 `dist[100]`이 정답이다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

int n, m;
vector<int> moveTo(101, 0);
vector<int> dist(101, -1);

void init()
{
    cin >> n >> m;

    for (int i = 0; i < n; ++i)
    {
        int x, y;
        cin >> x >> y;
        moveTo[x] = y;
    }

    for (int i = 0; i < m; ++i)
    {
        int x, y;
        cin >> x >> y;
        moveTo[x] = y;
    }
}

void bfs()
{
    queue<int> q;
    q.push(1);
    dist[1] = 0;

    while (!q.empty())
    {
        int cur = q.front();
        q.pop();

        for (int dice = 1; dice <= 6; ++dice)
        {
            int nx = cur + dice;
            if (nx > 100)
                continue;

            if (moveTo[nx] != 0)
            {
                nx = moveTo[nx];
            }

            if (dist[nx] == -1)
            {
                dist[nx] = dist[cur] + 1;
                q.push(nx);
            }
        }
    }
}

void solve()
{
    init();
    bfs();

    cout << dist[100] << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(100 \times 6) \approx O(1)$$
정점(칸)은 최대 100개이고,
각 칸에서 주사위 6가지 경우만 확인합니다.
따라서 전체 연산은 상수 크기이며, 일반식으로 보면 $$O(V+E)$$ 이지만 이 문제에서는 사실상 $$O(1)$$ 입니다.

### 2. 공간복잡도 : $$O(100) \approx O(1)$$
`moveTo`, `dist` 배열이 크기 101이고,
BFS 큐도 최대 100개 정도만 담을 수 있으므로 공간도 상수 수준입니다.
