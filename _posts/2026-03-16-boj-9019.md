## 문제 링크
[https://www.acmicpc.net/problem/9019](https://www.acmicpc.net/problem/9019)

## 문제 설명
정수 A를 정수 B로 바꾸려고 한다. 사용할 수 있는 연산은 다음 네 가지이다. (각 연산은 0~9999 범위에서 동작)

- D: n을 두 배로 하고 10000으로 나눈 나머지
- S: n에서 1을 뺀 값 (n이 0이면 9999)
- L: 각 자릿수를 왼쪽으로 회전
- R: 각 자릿수를 오른쪽으로 회전

A에서 B로 변환하기 위한 최소 연산 문자열을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 상태(0~9999)를 정점으로 보고, 한 상태에서 4가지 연산으로 다음 상태로 이동하는 **최단 경로 문제**입니다.
모든 연산 비용이 1이므로 **BFS**로 최소 연산 횟수를 보장할 수 있습니다.

### 1. 상태 정의 및 알고리즘 도출
- 정점: 0 ~ 9999 (총 10000개)
- 간선: 각 정점 x에서 D/S/L/R 연산을 적용한 다음 정점으로 이동
- `visited[x]` : x를 방문했는지 여부
- `pre[x]` : x에 오기 직전의 정점(이전 상태)
- `ops[x]` : x로 오기 위해 사용한 연산 문자(D/S/L/R)

동작 방식
- 시작점 A에서 BFS를 시작한다.
- 큐에서 꺼낸 현재 상태 cur에 대해 D/S/L/R을 적용해 nxt를 만든다.
- 아직 방문하지 않은 nxt를 방문 처리하고,
  - `pre[nxt] = cur`
  - `ops[nxt] = 해당 연산 문자`
  를 기록한 뒤 큐에 넣는다.
- 목표 상태 B에 도달하면 BFS를 종료한다.
- 종료 후 B부터 `pre[]`를 따라 A까지 역추적하면서 `ops[]`를 모으면 연산 문자열을 얻을 수 있다.
  역추적은 뒤집힌 순서로 쌓이므로 마지막에 reverse 한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <queue>
#include <string>
#include <algorithm>

using namespace std;

int a, b;
bool visited[10000];
int pre[10000];
char ops[10000];

int D(int x) { return (x * 2) % 10000; }
int S(int x) { return x == 0 ? 9999 : x - 1; }
int L(int x) { return (x % 1000) * 10 + x / 1000; }
int R(int x) { return (x % 10) * 1000 + x / 10; }

void init()
{
    cin >> a >> b;
    fill(visited, visited + 10000, false);
}

void bfs()
{
    queue<int> q;
    q.push(a);
    visited[a] = true;
    pre[a] = -1;

    while (!q.empty())
    {
        int cur = q.front();
        q.pop();

        if (cur == b)
            break;

        int nxt;

        nxt = D(cur);
        if (!visited[nxt])
        {
            visited[nxt] = true;
            pre[nxt] = cur;
            ops[nxt] = 'D';
            q.push(nxt);
        }

        nxt = S(cur);
        if (!visited[nxt])
        {
            visited[nxt] = true;
            pre[nxt] = cur;
            ops[nxt] = 'S';
            q.push(nxt);
        }

        nxt = L(cur);
        if (!visited[nxt])
        {
            visited[nxt] = true;
            pre[nxt] = cur;
            ops[nxt] = 'L';
            q.push(nxt);
        }

        nxt = R(cur);
        if (!visited[nxt])
        {
            visited[nxt] = true;
            pre[nxt] = cur;
            ops[nxt] = 'R';
            q.push(nxt);
        }
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--)
    {
        init();
        bfs();
        string ans;

        for (int cur = b; pre[cur] != -1; cur = pre[cur])
            ans += ops[cur];

        reverse(ans.begin(), ans.end());

        cout << ans << "\n";
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(10000) \approx O(1)$$
상태는 0~9999로 최대 10000개이고,
각 상태에서 최대 4개의 연산만 확인합니다.
따라서 BFS는 최악의 경우 모든 상태를 한 번 방문하므로 $$O(10000)$$ 수준(상수)입니다.
일반식으로는 $$O(V+E)$$ 이고 여기서 V=10000, E≈4V 입니다.

### 2. 공간복잡도 : $$O(10000) \approx O(1)$$
visited, pre, ops 배열이 크기 10000이고,
큐도 최악의 경우 10000개 정도를 담을 수 있으므로 공간도 상수 수준입니다.
