## 문제 링크
[https://www.acmicpc.net/problem/24511](https://www.acmicpc.net/problem/24511)

## 문제 설명
크기 N의 자료구조들이 줄지어 있고, 각 자료구조는 큐(0) 또는 스택(1)이다.
각 자료구조 i에는 초기 값 b[i]가 들어있다.

이후 M개의 값 c[i]가 순서대로 입력될 때마다,
맨 앞 자료구조에 값을 넣고(입력), 전체 자료구조를 한 번씩 통과시킨 뒤
맨 뒤에서 빠져나오는 값을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 실제로 N개의 큐/스택을 모두 시뮬레이션하면 비효율적이므로,
“결국 값이 이동하는 방식”만 관찰해서 **덱(deque)** 으로 한 번에 처리하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
핵심 관찰
- 스택(1)은 들어간 값이 바로 다시 나오는 구조(LIFO)라서 “전체 흐름”에서 실질적으로 순서를 바꾸지 않고 통과시키는 효과가 있습니다.
- 반면 큐(0)는 기존에 들어있던 값이 먼저 빠져나오기 때문에, 초기 값 b[i] 중에서 큐에 들어있는 값들만 실제 출력 흐름에 영향을 줍니다.

따라서,
- a[i]가 0(큐)인 위치의 b[i]만 모아서 덱에 저장한다.
- 입력이 들어올 때마다:
  - 새 입력 c[i]를 덱의 뒤에 넣고(push_back)
  - 덱의 앞에서 하나를 꺼내(pop_front) 출력한다.
- 덱의 앞에는 “다음에 빠져나올 값”들이 순서대로 유지되므로, 이 과정이 정답 흐름과 동일합니다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <deque>

using namespace std;

int n, m;
vector<int> a;
vector<long long> b, c;
deque<long long> dq;

void init() {
    cin >> n;

    a.assign(n, 0);
    b.assign(n, 0);

    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n; i++) cin >> b[i];

    cin >> m;
    c.assign(m, 0);
    for (int i = 0; i < m; i++) cin >> c[i];
}

void solve() {
    for (int i = 0; i < n; i++) {
        if (a[i] == 0) dq.push_front(b[i]);
    }

    for (int i = 0; i < m; i++) {
        dq.push_back(c[i]);
        cout << dq.front() << ' ';
        dq.pop_front();
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N + M)$$
초기 덱 구성에서 N개를 한 번 확인하고,
이후 M번에 대해 push_back/pop_front를 각각 한 번씩 수행합니다(덱 연산은 $$O(1)$$).
따라서 전체 시간복잡도는 $$O(N+M)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
덱에는 큐(0) 위치의 값들이 들어가며 최악의 경우 N개가 들어갈 수 있습니다.
입력 배열 저장까지 포함하면 전체적으로 $$O(N+M)$$ 수준이지만,
핵심 추가 공간은 덱의 $$O(N)$$ 입니다.
