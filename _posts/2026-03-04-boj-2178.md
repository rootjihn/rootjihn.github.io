## 문제 링크
[https://www.acmicpc.net/problem/2178](https://www.acmicpc.net/problem/2178)

## 문제 설명
N×M 크기의 미로가 주어진다. 1은 이동할 수 있는 칸, 0은 이동할 수 없는 칸이다.
(1,1)에서 출발하여 (N,M)까지 이동할 때 지나야 하는 최소 칸 수를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 격자에서 최단 거리를 구하는 전형적인 **그래프 탐색(BFS)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`visited[y][x]`를 (y, x) 칸까지 도달하는 데 필요한 최소 칸 수(거리)를 저장하는 배열이라고 정의하면,

- 시작점 (0,0)에서 BFS를 시작한다.
- 이동 비용이 모두 1(한 칸 이동)이고, BFS는 레벨 순서대로 확장하므로 최단 거리를 보장한다.
- 이동 가능한 칸(값 1)만 큐에 넣고, 벽(값 0)은 건너뛴다.
- 아직 방문하지 않은 칸에 대해 `visited[ny][nx] = visited[cur] + 1`로 거리 값을 기록한다.
- BFS가 끝나면 도착점 (n-1, m-1)의 visited 값이 정답이다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <string>

using namespace std;

struct Point
{
    int y, x;
};

int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

int n, m;
Point st;
Point ed;
vector<vector<int>> board;
vector<vector<int>> visited;

void init()
{
    cin >> n >> m;
    st = { 0,0 };
    ed = { n - 1,m - 1 };
    visited.assign(n, vector<int>(m, 0));
    board.assign(n, vector<int>(m, 0));

    for (int i = 0; i < n; ++i)
    {
        string s;
        cin >> s;
        for (int j = 0; j < m; ++j)
        {
            board[i][j] = s[j] - '0';
        }
    }
}

void bfs()
{
    queue<Point> q;
    q.push(st);
    visited[st.y][st.x] = 1;

    while (!q.empty())
    {
        Point cp = q.front();
        q.pop();

        if (cp.y == ed.y && cp.x == ed.x)
            return;

        for (int i = 0; i < 4; ++i)
        {
            Point np = { cp.y + dy[i], cp.x + dx[i] };

            if (np.y < 0 || np.x < 0 || np.y >= n || np.x >= m)
                continue;
            if (board[np.y][np.x] == 0)
                continue;
            if (visited[np.y][np.x] > 0)
                continue;

            visited[np.y][np.x] = visited[cp.y][cp.x] + 1;
            q.push(np);
        }
    }
}

void solve()
{
    init();
    bfs();
    cout << visited[ed.y][ed.x];
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times M)$$
BFS에서 각 칸은 최대 한 번 방문되고,
각 방문에서 4방향만 확인하므로 전체 연산량은 칸 수에 비례합니다.
따라서 시간복잡도는 $$O(NM)$$ 입니다.

### 2. 공간복잡도 : $$O(N \times M)$$
지도 `board`와 거리 배열 `visited`가 각각 $$O(NM)$$ 공간을 사용합니다.
BFS 큐도 최악의 경우 $$O(NM)$$까지 커질 수 있으므로 전체 공간복잡도는 $$O(NM)$$ 입니다.
