## 문제 링크
[https://www.acmicpc.net/problem/7569](https://www.acmicpc.net/problem/7569)

## 문제 설명
3차원 상자에 토마토가 들어 있다.

- 1: 익은 토마토
- 0: 익지 않은 토마토
- -1: 토마토가 없는 칸

하루가 지나면 익은 토마토의 인접한(상하좌우앞뒤) 익지 않은 토마토가 익는다.
모든 토마토가 익기까지 필요한 최소 일수를 출력하고,
처음부터 모두 익어있다면 0,
끝까지 모두 익지 못하면 -1을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 여러 시작점에서 동시에 퍼져나가는 형태이므로 **그래프 탐색(BFS)** 로 해결하는 문제입니다.
2차원(7576)과 동일한 원리지만, 방향이 6개(상하좌우 + 위아래 층)로 확장됩니다.

### 1. 상태 정의 및 알고리즘 도출
- `box[z][y][x]` : (z, y, x) 칸의 상태(익은 날 기록 포함)
- 처음에 값이 1인 칸들(이미 익은 토마토)을 모두 큐에 넣고 BFS를 시작한다. (멀티 소스 BFS)
- BFS로 전파될 때 익지 않은 토마토(0)를 만나면
  - `box[nz][ny][nx] = box[cp.z][cp.y][cp.x] + 1` 로 “익은 날짜(거리)”를 기록하고 큐에 넣는다.
- BFS가 끝난 뒤에도 0이 남아있으면 도달 불가능이므로 -1이다.
- 0이 없다면 가장 큰 값이 마지막으로 익은 날이며,
  처음 익은 칸이 1로 시작했으므로 정답은 `max_day - 1`이다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

struct Point
{
    int z, y, x;
};

int dz[6] = {0, 0, 0, 0, 1, -1};
int dy[6] = {-1, 1, 0, 0, 0, 0};
int dx[6] = {0, 0, -1, 1, 0, 0};

int n, m, h;
vector<vector<vector<int>>> box;
queue<Point> q;

void bfs()
{
    while (!q.empty())
    {
        Point cp = q.front();
        q.pop();

        for (int i = 0; i < 6; i++)
        {
            int nz = cp.z + dz[i];
            int ny = cp.y + dy[i];
            int nx = cp.x + dx[i];

            if (nz < 0 || ny < 0 || nx < 0 || nz >= h || ny >= n || nx >= m)
                continue;

            if (box[nz][ny][nx] == 0)
            {
                box[nz][ny][nx] = box[cp.z][cp.y][cp.x] + 1;
                q.push({nz, ny, nx});
            }
        }
    }
}

void init()
{
    cin >> m >> n >> h;

    box.assign(h, vector<vector<int>>(n, vector<int>(m)));
    for (int i = 0; i < h; i++)
    {
        for (int j = 0; j < n; j++)
        {
            for (int k = 0; k < m; k++)
            {
                cin >> box[i][j][k];
                if (box[i][j][k] == 1)
                {
                    q.push({i, j, k});
                }
            }
        }
    }
}

void solve()
{
    init();
    bfs();

    int max_day = 0;
    for (int i = 0; i < h; i++)
    {
        for (int j = 0; j < n; j++)
        {
            for (int k = 0; k < m; k++)
            {
                if (box[i][j][k] == 0)
                {
                    cout << -1;
                    return;
                }
                if (max_day < box[i][j][k])
                {
                    max_day = box[i][j][k];
                }
            }
        }
    }

    cout << max_day - 1;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(H \times N \times M)$$
BFS에서 각 칸은 최대 한 번 큐에 들어가며(0 → 양수로 바뀌면 재방문 없음),
각 칸에서 6방향만 확인합니다.
따라서 전체 연산량은 칸 수에 비례하여 $$O(HNM)$$ 입니다.
입력/검사 과정도 전체 칸을 한 번 훑으므로 동일하게 $$O(HNM)$$ 입니다.

### 2. 공간복잡도 : $$O(H \times N \times M)$$
3차원 배열 `box`가 $$O(HNM)$$ 공간을 사용합니다.
큐도 최악의 경우 많은 칸이 들어갈 수 있어 $$O(HNM)$$ 수준까지 커질 수 있으므로 전체 공간도 $$O(HNM)$$ 입니다.
