## 문제 링크
https://www.acmicpc.net/problem/17219

## 문제 설명
N개의 사이트 주소와 비밀번호가 주어지고, 이후 M개의 사이트 주소가 주어진다.
각 사이트 주소에 해당하는 비밀번호를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “문자열 키(사이트) → 값(비밀번호)”을 빠르게 찾아야 하므로 **해시맵(unordered_map)** 을 사용하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- `find_pw[site] = pw` 형태로 사이트 주소를 키로, 비밀번호를 값으로 저장한다.
- 이후 질의로 들어오는 사이트 주소 `find_site`에 대해 `find_pw[find_site]`를 출력한다.
- `unordered_map`은 평균적으로 삽입/탐색이 $$O(1)$$ 이라 많은 질의도 빠르게 처리할 수 있다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <unordered_map>
#include <string>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    unordered_map<string, string> find_pw;

    for (int i = 0; i < n; i++)
    {
        string site, pw;
        cin >> site >> pw;

        find_pw[site] = pw;
    }

    for (int i = 0; i < m; i++)
    {
        string find_site;
        cin >> find_site;

        cout << find_pw[find_site] << "\n";
    }

    return 0;
}
```

---

## 복잡도 분석
### 1. 시간복잡도 : $$O(N + M)$$ (평균)
사이트/비밀번호 저장이 N번(평균 $$O(1)$$),
질의 탐색/출력이 M번(평균 $$O(1)$$)이므로 전체가 평균적으로 $$O(N+M)$$ 입니다.
(해시 충돌이 심한 최악의 경우는 더 느려질 수 있지만 일반적으로 평균 성능을 사용합니다.)

### 2. 공간복잡도 : $$O(N)$$
해시맵에 N개의 (사이트, 비밀번호) 쌍을 저장하므로 $$O(N)$$ 공간이 필요합니다.
