## 문제 링크
[https://www.acmicpc.net/problem/1074](https://www.acmicpc.net/problem/1074)

## 문제 설명
크기가 2^N × 2^N 인 2차원 배열을 Z 모양으로 탐색한다.
N, r, c가 주어졌을 때, (r, c)를 몇 번째로 방문하는지 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 정사각형을 4등분하며 탐색 순서(왼쪽위 → 오른쪽위 → 왼쪽아래 → 오른쪽아래)를 유지하는 **분할정복(재귀)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
현재 정사각형의 왼쪽 위 좌표를 (y, x), 한 변의 길이를 size라고 하면,

- (r, c)가 현재 정사각형 범위 안에 있다면, size/2로 4분할하여 Z 순서대로 재귀 탐색한다.
- (r, c)가 현재 정사각형 범위 밖에 있다면, 그 정사각형은 통째로 건너뛰는 구간이므로
  해당 구간의 칸 개수인 `size^2` 만큼 ans에 더해준다.
- (y, x)가 (r, c)와 같아지는 순간의 ans가 곧 (r, c)를 방문하는 순서이다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

int n, r, c;
int ans;

void divide(int y, int x, int size)
{
    if (y == r && x == c)
    {
        cout << ans;
        exit(0);
    }
    else if (r < y + size && c < x + size && r >= y && c >= x)
    {
        divide(y, x, size / 2);
        divide(y, x + size / 2, size / 2);
        divide(y + size / 2, x, size / 2);
        divide(y + size / 2, x + size / 2, size / 2);
    }
    else
    {
        ans += pow(size, 2);
    }
}

int main()
{
    cin >> n >> r >> c;
    int size = pow(2, n);
    ans = 0;
    divide(0, 0, size);

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(4N) \approx O(N)$$
매 단계에서 4개로 재귀 호출이 보이지만,
범위 밖인 정사각형은 즉시 `ans += size^2`로 끝나고 더 내려가지 않습니다.
실제로는 (r, c)가 포함된 경로를 따라 깊이 N까지 내려가며, 각 레벨에서 상수 개의 분기만 의미 있게 처리됩니다.
따라서 전체 수행은 대략 N에 비례합니다.

### 2. 공간복잡도 : $$O(N)$$
재귀 호출 깊이가 최대 N(한 변을 2로 나누는 횟수) 이므로,
호출 스택이 $$O(N)$$ 공간을 사용합니다.
