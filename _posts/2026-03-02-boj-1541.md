## 문제 링크
[https://www.acmicpc.net/problem/1541](https://www.acmicpc.net/problem/1541)

## 문제 설명
세준이는 양수와 '+' , '-' 그리고 괄호를 가지고 식을 만들었다.
괄호를 적절히 쳐서 식의 값을 최소로 만들려고 한다.
주어진 식에서 괄호를 쳐서 만들 수 있는 최솟값을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 '-'가 등장한 이후의 값을 최대한 크게 만들어서 한 번에 빼면 최솟값이 되므로 **그리디(Greedy)** 로 해결하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- 식을 왼쪽부터 읽으며 숫자를 만들고, 연산자를 만날 때마다 현재까지 만든 숫자를 결과에 반영한다.
- 핵심은 첫 번째 '-'가 등장한 뒤부터는 이후에 나오는 모든 수를 전부 빼면(괄호로 묶어 빼는 효과) 최솟값이 된다는 점이다.
- 이를 구현하기 위해 `minus_mode`를 사용한다.
  - `minus_mode == false` : 아직 '-'를 만나지 않았으므로 숫자를 더한다.
  - `minus_mode == true` : 한 번이라도 '-'를 만난 이후이므로 이후 숫자는 모두 뺀다.
- 문자열 끝에 도달했을 때 마지막 숫자도 동일한 규칙으로 반영한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string str;
    cin >> str;

    bool minus_mode = false;
    int ans = 0;
    int num = 0;

    for (int i = 0; i < str.size(); i++)
    {
        if (str[i] >= '0' && str[i] <= '9')
            num = num * 10 + (str[i] - '0');
        else
        {
            if (minus_mode)
                ans -= num;
            else
                ans += num;

            num = 0;

            if (str[i] == '-')
            {
                minus_mode = true;
            }
        }
    }

    if (minus_mode)
        ans -= num;
    else
        ans += num;

    cout << ans;

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(L)$$
문자열을 길이 L만큼 한 번 순회하며 숫자 파싱과 연산 처리를 수행합니다.
따라서 시간복잡도는 $$O(L)$$ 입니다.

### 2. 공간복잡도 : $$O(1)$$
추가로 사용하는 변수는 상수 개수이므로 $$O(1)$$ 공간을 사용합니다.
