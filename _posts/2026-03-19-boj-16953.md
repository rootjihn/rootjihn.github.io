## 문제 링크
[https://www.acmicpc.net/problem/16953](https://www.acmicpc.net/problem/16953)

## 문제 설명
정수 A를 정수 B로 바꾸려고 한다. 사용할 수 있는 연산은 다음 두 가지이다.

- A를 2를 곱한다.
- A의 오른쪽에 1을 추가한다. (예: 10 → 101)

A를 B로 바꾸기 위한 연산의 최소 횟수를 출력한다.
만들 수 없으면 -1을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 가능한 연산이 2가지이고 값이 계속 증가하기 때문에,
A에서 시작해 B를 넘기 전까지 탐색하는 방식으로 해결할 수 있습니다.
(또는 B에서 A로 거꾸로 줄여가는 그리디 풀이도 가능)

### 1. 상태 정의 및 알고리즘 도출
- `cur` : 현재 값
- `cnt` : 지금까지 사용한 연산 횟수(문제 요구 출력은 시작 포함 형태라 코드에서는 1부터 시작)

동작 방식
- DFS로 두 연산을 모두 시도한다.
  - `cur * 2`
  - `cur * 10 + 1`
- 가지치기:
  - `cur > b`이면 더 진행해도 b에 도달할 수 없으므로 중단한다.
  - `cnt >= ans`이면 이미 더 좋은 답이 있으므로 중단한다.
- `cur == b`이면 ans를 갱신한다.
- 탐색이 끝난 뒤 ans가 갱신되지 않았으면 -1을 출력한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <algorithm>
#include <climits>

using namespace std;

long long a, b;
long long ans = INT_MAX;

void init()
{
    cin >> a >> b;
}

void dfs(long long cur, long long cnt)
{
    if (cnt >= ans)
        return;

    if (cur > b)
        return;

    if (cur == b)
    {
        ans = min(cnt, ans);
        return;
    }

    dfs(cur * 2, cnt + 1);
    dfs(cur * 10 + 1, cnt + 1);
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    dfs(a, 1);
    ans == INT_MAX ? cout << -1 : cout << ans;

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : 탐색 깊이 D에 대해 $$O(2^D)$$ (상한)
각 단계에서 2가지 연산으로 분기하므로 최악의 경우 지수적으로 늘어날 수 있습니다.
다만 값이 빠르게 증가하고 `cur > b`에서 가지치기가 되기 때문에 실제 탐색량은 제한됩니다.
(입력 범위에서는 충분히 통과 가능한 경우가 많습니다.)

### 2. 공간복잡도 : $$O(D)$$
재귀 DFS의 호출 깊이가 D이므로 호출 스택이 $$O(D)$$ 공간을 사용합니다.
