## 문제 링크
[https://www.acmicpc.net/problem/1629](https://www.acmicpc.net/problem/1629)

## 문제 설명
자연수 A, B, C가 주어졌을 때, $$A^B \bmod C$$ 를 출력한다.
(A, B, C는 범위가 커서 단순히 곱하면 오버플로우/시간 초과가 발생할 수 있다.)

---

## 풀이 전략 (Approach)
이 문제는 거듭제곱을 빠르게 계산하는 **분할정복(빠른 거듭제곱, exponentiation by squaring)** 을 사용합니다.
지수 B를 반으로 줄여가며 계산하면 $$O(\log B)$$ 시간에 구할 수 있습니다.

### 1. 상태 정의 및 알고리즘 도출
함수 `solve(a, b, c)`를 $$a^b \bmod c$$ 를 반환하는 함수라고 하면,

- b가 1이면 $$a \bmod c$$ 가 된다. (기저 조건)
- b를 절반으로 나눈 값을 먼저 구한다.
  - $$tmp = a^{\lfloor b/2 \rfloor} \bmod c$$
- 짝수/홀수에 따라 결합한다.
  - b가 짝수: $$a^b = (a^{b/2})^2$$
  - b가 홀수: $$a^b = (a^{\lfloor b/2 \rfloor})^2 \cdot a$$
- 곱셈마다 모듈러를 적용해 값이 커지는 것을 방지한다.

수식으로 쓰면:

- b가 짝수일 때  
$$a^b \bmod c = (tmp \cdot tmp) \bmod c$$

- b가 홀수일 때  
$$a^b \bmod c = (tmp \cdot tmp \cdot a) \bmod c$$

## 코드 (C++)
```cpp
#include <iostream>

using namespace std;

long long solve(long long a, long long b, long long c)
{
    if (b == 1)
        return a % c;

    long long tmp = solve(a, b / 2, c);
    tmp = (tmp * tmp) % c;

    if (b % 2 == 1)
        tmp = (tmp * a) % c;

    return tmp;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b, c;
    cin >> a >> b >> c;

    cout << solve(a, b, c);

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(\log B)$$
재귀 호출에서 지수 b가 매번 절반으로 줄어듭니다.
따라서 호출 깊이는 $$\log B$$이고, 각 단계는 상수 시간 연산이므로 전체 시간복잡도는 $$O(\log B)$$ 입니다.

### 2. 공간복잡도 : $$O(\log B)$$
재귀 호출 깊이가 $$\log B$$ 이므로 호출 스택이 $$O(\log B)$$ 공간을 사용합니다.
