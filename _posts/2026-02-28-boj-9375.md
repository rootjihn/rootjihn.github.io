## 문제 링크
[https://www.acmicpc.net/problem/9375](https://www.acmicpc.net/problem/9375)

## 문제 설명
해빈이는 각 테스트 케이스마다 의상을 조합해서 입을 수 있다.
의상은 (이름, 종류)로 주어지며, 같은 종류의 의상은 동시에 하나만 착용할 수 있다.
아무것도 입지 않는 경우를 제외하고, 서로 다른 옷의 조합 개수를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “종류별 의상 개수”를 세고 곱셈 원리를 적용하는 **경우의 수(조합)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
종류(카테고리)별 의상 개수를 `cnt[type]`라고 하면,

- 한 종류에서 가능한 선택은
  - 그 종류의 의상 중 1개를 고르는 경우: `cnt[type]`
  - 그 종류를 아예 안 고르는 경우: `1`
  따라서 총 `cnt[type] + 1` 가지입니다.

종류들이 서로 독립이므로 곱셈 원리에 의해 전체 경우의 수는

$$
\text{total} = \prod_{\text{type}} (cnt[type] + 1)
$$

여기에는 “모든 종류를 안 고르는 경우(아무것도 안 입는 경우)” 1개가 포함되므로,
문제 조건에 따라 마지막에 1을 빼서 정답을 구합니다.

$$
\text{answer} = \left(\prod_{\text{type}} (cnt[type] + 1)\right) - 1
$$

## 코드 (C++)
```cpp
#include <iostream>
#include <string>
#include <map>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;

    int n;
    string name, catalog;

    while(t--)
    {
        map<string, int> m;
        cin >> n;
        while(n--)
        {
            cin >> name >> catalog;

            if(m.find(catalog) == m.end())
            {
                m.insert({catalog, 1});
            }
            else
            {
                m[catalog]++;
            }
        }

        int ans = 1;

        for(auto x : m)
        {
            ans *= (x.second + 1);
        }

        ans--;

        cout << ans << "\n";
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \log K)$$
각 테스트 케이스에서 의상을 N개 입력받으며,
`map`에 삽입/탐색은 원소 개수를 K(종류 수)라고 할 때 $$O(\log K)$$ 입니다.
따라서 입력 처리 시간은 $$O(N \log K)$$ 이고,
마지막에 종류 K개를 순회하며 곱하는 과정은 $$O(K)$$ 입니다.
전체는 $$O(N \log K + K)$$ 이며 보통 $$O(N \log K)$$ 로 봅니다.

### 2. 공간복잡도 : $$O(K)$$
종류별 개수를 `map`에 저장하므로 종류 수 K만큼 공간이 필요합니다.
