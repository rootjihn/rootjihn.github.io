## 문제 링크
[https://www.acmicpc.net/problem/11403](https://www.acmicpc.net/problem/11403)

## 문제 설명
가중치가 없는 방향 그래프가 주어졌을 때, 모든 정점 i에서 j로 가는 경로가 있는지(도달 가능 여부)를 구해
도달 가능하면 1, 아니면 0을 출력한다.

입력은 인접 행렬 형태로 주어진다.

---

## 풀이 전략 (Approach)
이 문제는 각 정점에서 출발해 도달 가능한 정점을 찾으면 되므로,
정점마다 DFS/BFS를 수행하여 도달 가능 여부를 구할 수 있습니다.

### 1. 상태 정의 및 알고리즘 도출
- `adj[u][v]` : u에서 v로 직접 가는 간선이 있으면 1, 없으면 0
- `visited[v]` : 시작 정점에서 v에 도달 가능하면 1, 아니면 0

동작 방식
- 시작 정점 i를 0부터 N-1까지 반복한다.
- 매번 `visited`를 초기화한 뒤 DFS(i)를 수행한다.
- DFS로 도달 가능한 모든 정점을 방문 처리하면 `visited[j]`가 곧 i→j 경로 존재 여부가 된다.
- 각 i에 대해 `visited` 배열을 한 줄로 출력한다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

int N;
vector<vector<int>> adj;
vector<int> visited;

void init()
{
    cin >> N;
    adj.assign(N, vector<int>(N, 0));
    visited.assign(N, 0);

    for (int i = 0; i < N; i++)
    {
        for (int j = 0; j < N; j++)
        {
            cin >> adj[i][j];
        }
    }
}

void dfs(int now)
{
    for (int i = 0; i < N; i++)
    {
        if (adj[now][i] == 0)
            continue;
        if (visited[i] == 1)
            continue;

        visited[i] = 1;
        dfs(i);
    }
}

void solve()
{
    init();

    for (int i = 0; i < N; ++i)
    {
        visited.assign(N, 0);
        dfs(i);
        for (int j = 0; j < N; ++j)
        {
            cout << visited[j] << " ";
        }
        cout << "\n";
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N^3)$$
정점마다(총 N번) DFS를 수행합니다.
DFS 한 번은 인접 행렬을 사용하므로, 각 정점에서 가능한 다음 정점을 확인하기 위해 N개를 훑습니다.
최악의 경우 DFS 과정에서 N개의 정점을 방문하며 매번 N개를 확인하므로 DFS 1회가 $$O(N^2)$$ 입니다.
따라서 N번 반복하면 $$O(N^3)$$ 입니다.

### 2. 공간복잡도 : $$O(N^2)$$
인접 행렬 `adj`가 $$O(N^2)$$ 공간을 사용하고,
방문 배열 `visited`는 $$O(N)$$ 입니다.
따라서 전체 공간복잡도는 $$O(N^2)$$ 입니다.
