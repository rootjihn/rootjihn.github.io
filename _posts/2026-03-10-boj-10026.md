## 문제 링크
[https://www.acmicpc.net/problem/10026](https://www.acmicpc.net/problem/10026)

## 문제 설명
N×N 그리드에 R, G, B로 색이 칠해져 있다.
상하좌우로 같은 색이 연결되어 있으면 같은 구역으로 본다.

- 일반인: R/G/B를 각각 다른 색으로 구분
- 적록색약: R과 G를 같은 색으로 구분

일반인이 봤을 때의 구역 개수와, 적록색약이 봤을 때의 구역 개수를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 격자에서 연결된 같은 색 영역의 개수를 세는 **그래프 탐색(DFS/BFS)** 문제입니다.
일반인 기준과 적록색약 기준을 각각 탐색하면 됩니다.

### 1. 상태 정의 및 알고리즘 도출
- `board[y][x]` : (y, x) 칸의 색(R/G/B)
- `visited1[y][x]` : 일반인 기준 방문 여부
- `visited2[y][x]` : 적록색약 기준 방문 여부

동작 방식
- 모든 칸을 순회하며 방문하지 않은 칸을 발견하면 DFS를 시작한다.
- 일반인 DFS(visited1):
  - 시작 칸의 색과 같은 칸만 계속 확장한다.
- 적록색약 DFS(visited2):
  - 시작 색이 R 또는 G이면, 다음 칸이 R 또는 G인 경우를 같은 구역으로 확장한다.
  - 시작 색이 B이면, 다음 칸도 B인 경우만 확장한다.
- DFS를 시작한 횟수가 곧 구역의 개수이므로, 각각 ans1(일반), ans2(색약)을 증가시킨다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

struct Point
{
    int y, x;
    char color;
};

int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

int n;
int ans1, ans2;
vector<vector<int>> board;
vector<vector<int>> visited1;
vector<vector<int>> visited2;

void init()
{
    cin >> n;
    board.assign(n, vector<int>(n, 0));
    visited1.assign(n, vector<int>(n, 0));
    visited2.assign(n, vector<int>(n, 0));
    string s;
    for (int i = 0; i < n; ++i)
    {
        cin >> s;
        int j = 0;
        for (char x : s)
        {
            board[i][j++] = x;
        }
    }
}

void dfs1(Point st)
{
    visited1[st.y][st.x] = 1;
    char now_color = st.color;

    for (int dir = 0; dir < 4; ++dir)
    {
        int ny = st.y + dy[dir];
        int nx = st.x + dx[dir];

        if (ny < 0 || nx < 0 || ny >= n || nx >= n)
            continue;
        if (visited1[ny][nx] == 1)
            continue;
        if (board[ny][nx] != now_color)
            continue;

        dfs1({ ny,nx,now_color });
    }
}

void dfs2(Point st)
{
    visited2[st.y][st.x] = 1;
    char now_color = st.color;

    if (now_color == 'R' || now_color == 'G')
    {
        for (int dir = 0; dir < 4; ++dir)
        {
            int ny = st.y + dy[dir];
            int nx = st.x + dx[dir];

            if (ny < 0 || nx < 0 || ny >= n || nx >= n)
                continue;
            if (visited2[ny][nx] == 1)
                continue;
            if (board[ny][nx] != 'R' && board[ny][nx] != 'G')
                continue;

            dfs2({ ny,nx,now_color });
        }
    }
    else
    {
        for (int dir = 0; dir < 4; ++dir)
        {
            int ny = st.y + dy[dir];
            int nx = st.x + dx[dir];

            if (ny < 0 || nx < 0 || ny >= n || nx >= n)
                continue;
            if (visited2[ny][nx] == 1)
                continue;
            if (board[ny][nx] != now_color)
                continue;

            dfs2({ ny,nx,now_color });
        }
    }
}

void solve()
{
    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < n; ++j)
        {
            if (visited1[i][j] == 0)
            {
                dfs1({ i,j,char(board[i][j]) });
                ans1++;
            }

            if (visited2[i][j] == 0)
            {
                dfs2({ i,j,char(board[i][j]) });
                ans2++;
            }
        }
    }

    cout << ans1 << " " << ans2;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times N)$$
일반인 DFS에서 각 칸은 최대 한 번 방문되고, 각 방문에서 4방향만 확인합니다.
적록색약 DFS에서도 동일하게 각 칸은 최대 한 번 방문됩니다.
따라서 두 번의 탐색을 하더라도 전체 시간은 $$O(N^2)$$ 입니다.

### 2. 공간복잡도 : $$O(N \times N)$$
지도 `board`와 방문 배열 `visited1`, `visited2`가 각각 $$O(N^2)$$ 공간을 사용합니다.
재귀 DFS의 호출 스택도 최악의 경우 $$O(N^2)$$까지 깊어질 수 있으나, 보통은 $$O(N^2)$$가 지배적입니다.
