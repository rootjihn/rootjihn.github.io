## 문제 링크
[https://www.acmicpc.net/problem/1991](https://www.acmicpc.net/problem/1991)

## 문제 설명
이진 트리가 주어졌을 때, 다음 세 가지 순회 결과를 출력한다.

- 전위 순회(Preorder): 루트 → 왼쪽 → 오른쪽
- 중위 순회(Inorder): 왼쪽 → 루트 → 오른쪽
- 후위 순회(Postorder): 왼쪽 → 오른쪽 → 루트

입력은 각 노드에 대해 (부모, 왼쪽 자식, 오른쪽 자식)이 주어지며,
자식이 없으면 '.'으로 주어진다.

---

## 풀이 전략 (Approach)
이 문제는 이진 트리를 저장한 뒤, 재귀로 전위/중위/후위 순회를 그대로 구현하면 됩니다.

### 1. 상태 정의 및 알고리즘 도출
- 노드는 'A'~'Z'로 주어지므로 인덱스 0~25로 매핑한다.
- `adj[p][0]` : p의 왼쪽 자식 (없으면 -1)
- `adj[p][1]` : p의 오른쪽 자식 (없으면 -1)

순회 규칙
- 전위: 현재 출력 → 왼쪽 재귀 → 오른쪽 재귀
- 중위: 왼쪽 재귀 → 현재 출력 → 오른쪽 재귀
- 후위: 왼쪽 재귀 → 오른쪽 재귀 → 현재 출력

루트는 항상 'A'이므로 인덱스 0에서 시작한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

int n;
vector<vector<int>> adj;

void init()
{
    cin >> n;
    adj.assign(26, vector<int>(2, -1));

    for (int i = 0; i < n; ++i)
    {
        char parent, left, right;
        cin >> parent >> left >> right;

        int p = parent - 'A';

        if (left != '.')
            adj[p][0] = left - 'A';
        if (right != '.')
            adj[p][1] = right - 'A';
    }
}

void preorder(int cur)
{
    if (cur == -1)
        return;
    cout << char(cur + 'A');
    preorder(adj[cur][0]);
    preorder(adj[cur][1]);
}

void inorder(int cur)
{
    if (cur == -1)
        return;
    inorder(adj[cur][0]);
    cout << char(cur + 'A');
    inorder(adj[cur][1]);
}

void postorder(int cur)
{
    if (cur == -1)
        return;
    postorder(adj[cur][0]);
    postorder(adj[cur][1]);
    cout << char(cur + 'A');
}

void solve()
{
    preorder(0);
    cout << "\n";
    inorder(0);
    cout << "\n";
    postorder(0);
    cout << "\n";
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N)$$
각 순회는 모든 노드를 정확히 한 번씩 방문하여 출력합니다.
따라서 전위/중위/후위 각각 $$O(N)$$ 이고, 총합도 $$O(N)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
트리 정보를 저장하는 `adj`가 $$O(N)$$ 공간을 사용합니다.
재귀 호출 깊이는 트리 높이만큼이고 최악의 경우 $$O(N)$$까지 갈 수 있으므로,
호출 스택까지 포함하면 전체도 $$O(N)$$ 수준입니다.
