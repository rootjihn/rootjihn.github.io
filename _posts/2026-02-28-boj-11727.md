## 문제 링크
[https://www.acmicpc.net/problem/11727](https://www.acmicpc.net/problem/11727)

## 문제 설명
2×n 크기의 직사각형을 1×2, 2×1, 2×2 타일로 채우는 방법의 수를 구하는 프로그램을 작성하시오.
결과는 10,007로 나눈 나머지를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 전형적인 **Dynamic Programming(DP)** 문제입니다.

### 1. 상태 정의 및 점화식 도출
`dp[i]`를 2×i 크기의 직사각형을 타일로 채우는 방법의 수라고 정의하면,

- 마지막에 세로 타일(2×1) 1개를 세우는 경우: `dp[i-1]`
- 마지막 2열을 채우는 경우:
  - 가로 타일(1×2) 2개를 쌓는 경우
  - 2×2 타일 1개를 놓는 경우  
  이 두 경우는 모두 “마지막 2열을 한 번에 채운다”는 점에서 `dp[i-2]`에 대해 2가지가 생깁니다.

따라서,

$$
dp[i] = dp[i-1] + 2 \cdot dp[i-2]
$$

문제에서 10007로 나눈 나머지를 구하므로 매 단계에서 모듈러 연산을 적용합니다.

$$
dp[i] = (dp[i-1] + 2 \cdot dp[i-2]) \bmod 10007
$$

기저 조건은 다음과 같습니다.

$$
dp[1]=1,\quad dp[2]=3
$$

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

int n;
vector<int> dp;

void init()
{
    cin >> n;
    dp.assign(n + 1, 0);
}

void solve()
{
    init();

    dp[1] = 1;
    if (n >= 2)
        dp[2] = 3;

    for (int i = 3; i <= n; ++i)
    {
        dp[i] = (dp[i - 1] + 2 * dp[i - 2]) % 10007;
    }

    cout << dp[n] % 10007;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N)$$
dp[3]부터 dp[n]까지 한 번씩 계산하므로 반복 횟수가 N에 비례합니다.
따라서 시간복잡도는 $$O(N)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
dp 배열에 0부터 n까지 저장하므로 $$O(N)$$ 공간을 사용합니다.
