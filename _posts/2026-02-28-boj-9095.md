## 문제 링크
https://www.acmicpc.net/problem/9095

## 문제 설명
정수 n이 주어졌을 때, n을 1, 2, 3의 합으로 나타내는 방법의 수를 구하는 프로그램을 작성하시오.

---

## 풀이 전략 (Approach)
이 문제는 전형적인 **Dynamic Programming(DP)** 문제입니다.

### 1. 상태 정의 및 점화식 도출
`d[x]`를 정수 x를 1, 2, 3의 합으로 나타내는 방법의 수라고 정의하면,

- 마지막에 1을 더한 경우: `d[x-1]`
- 마지막에 2를 더한 경우: `d[x-2]`
- 마지막에 3을 더한 경우: `d[x-3]`

따라서,

$$
d[x] = d[x-1] + d[x-2] + d[x-3]
$$

기저 조건은 다음과 같습니다.

$$
d[1]=1,\quad d[2]=2,\quad d[3]=4
$$

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

int d[11];

int dp(int x)
{
    if (x == 1)
        return d[x] = 1;
    if (x == 2)
        return d[x] = 2;
    if (x == 3)
        return d[x] = 4;

    if (d[x] != 0)
        return d[x];

    return d[x] = dp(x - 3) + dp(x - 2) + dp(x - 1);
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t, n;

    cin >> t;

    while (t--)
    {
        for (int i = 0; i < 11; i++)
        {
            d[i] = 0;
        }
        cin >> n;
        cout << dp(n) << "\n";
    }

    return 0;
}
```
