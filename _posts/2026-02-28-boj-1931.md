## 문제 링크
https://www.acmicpc.net/problem/1931

## 문제 설명
한 개의 회의실에서 N개의 회의를 진행하려고 한다. 각 회의는 시작 시간과 끝나는 시간이 주어진다.
회의가 겹치지 않게 하면서 사용할 수 있는 회의의 최대 개수를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 **끝나는 시간이 빠른 회의를 먼저 선택**하는 것이 최적이므로 **그리디(Greedy)** 로 해결하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- 회의를 “끝나는 시간 오름차순”으로 정렬한다.
  - 끝나는 시간이 같다면 “시작 시간 오름차순”으로 정렬한다.
- 정렬된 순서대로 보면서,
  - 이전에 선택한 회의의 종료 시간 `last_time` 이후에 시작하는 회의라면 선택한다.
  - 선택할 때마다 `cnt++`, `last_time = end`로 갱신한다.
- 이렇게 하면 항상 가능한 한 빨리 회의실을 비우는 선택을 하게 되어, 이후에 더 많은 회의를 넣을 수 있다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

struct Meeting
{
    int start, end;
};

bool compare(Meeting &a, Meeting &b)
{
    if (a.end != b.end)
        return a.end < b.end;
    return a.start < b.start;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<Meeting> v(n);

    for (int i = 0; i < n; i++)
        cin >> v[i].start >> v[i].end;

    sort(v.begin(), v.end(), compare);

    int cnt = 0;
    int last_time = 0;

    for (int i = 0; i < n; i++)
    {
        if (v[i].start >= last_time)
        {
            cnt++;
            last_time = v[i].end;
        }
    }

    cout << cnt;

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \log N)$$
회의 정보를 끝나는 시간 기준으로 정렬하는 데 $$O(N \log N)$$ 이 필요하고,
정렬 이후 한 번 순회하며 선택하는 과정은 $$O(N)$$ 입니다.
따라서 전체 시간복잡도는 $$O(N \log N)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
회의 정보를 저장하는 벡터 `v`가 $$O(N)$$ 공간을 사용합니다.
(정렬 과정에서 추가로 큰 메모리를 요구하지 않으므로 전체도 $$O(N)$$ 수준입니다.)
