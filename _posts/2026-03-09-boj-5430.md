## 문제 링크
[https://www.acmicpc.net/problem/5430](https://www.acmicpc.net/problem/5430)

## 문제 설명
정수 배열에 대해 다음 두 가지 함수가 있다.

- R(Reverse): 배열에 있는 수의 순서를 뒤집는다.
- D(Delete): 첫 번째 수를 버린다. 배열이 비어있는데 D를 사용하면 에러가 발생한다.

함수 문자열 p와 배열이 주어졌을 때, 최종 결과를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 R이 나올 때마다 실제로 배열을 뒤집으면 시간 초과가 나기 쉬우므로,
“뒤집힌 상태인지”만 토글로 관리하면서 D 연산을 앞/뒤에서 수행하는 방식으로 해결하는 **덱(deque) 시뮬레이션** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- 입력 배열은 덱(deque)에 저장한다.
- `rev` : 현재 배열이 뒤집힌 상태인지 여부 (false=정방향, true=역방향)
- 명령 처리:
  - 'R'이면 `rev = !rev` 로 상태만 바꾼다(실제 reverse는 하지 않음).
  - 'D'이면
    - 덱이 비어있으면 error
    - `rev == false`면 front 삭제(pop_front)
    - `rev == true`면 back 삭제(pop_back)
- 모든 명령을 처리한 뒤 출력할 때만 `rev` 상태에 따라 앞에서부터/뒤에서부터 출력한다.
- 배열 입력 문자열(예: "[1,2,3]")은 숫자만 파싱해서 덱에 넣는다.

## 코드 (C++)
```cpp
#include <iostream>
#include <string>
#include <deque>
#include <cctype>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--)
    {
        string p, arr;
        int n;
        cin >> p;
        cin >> n;
        cin >> arr;

        deque<int> dq;
        string num = "";

        for (char c : arr)
        {
            if (isdigit(c))
            {
                num += c;
            }
            else
            {
                if (!num.empty())
                {
                    dq.push_back(stoi(num));
                    num = "";
                }
            }
        }

        bool rev = false;
        bool error = false;

        for (char cmd : p)
        {
            if (cmd == 'R')
            {
                rev = !rev;
            }
            else if (cmd == 'D')
            {
                if (dq.empty())
                {
                    error = true;
                    break;
                }

                if (!rev)
                    dq.pop_front();
                else
                    dq.pop_back();
            }
        }

        if (error)
        {
            cout << "error\n";
            continue;
        }

        cout << "[";
        if (!dq.empty())
        {
            if (!rev)
            {
                for (int i = 0; i < (int)dq.size(); i++)
                {
                    cout << dq[i];
                    if (i != (int)dq.size() - 1)
                        cout << ",";
                }
            }
            else
            {
                for (int i = (int)dq.size() - 1; i >= 0; i--)
                {
                    cout << dq[i];
                    if (i != 0)
                        cout << ",";
                }
            }
        }
        cout << "]\n";
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(|p| + n)$$
명령 문자열 p를 한 번 순회하며 R/D를 처리하므로 $$O(|p|)$$,
입력 배열을 파싱하여 덱에 넣는 과정이 $$O(n)$$,
출력도 각 원소를 한 번씩 출력하므로 $$O(n)$$ 입니다.
따라서 전체는 $$O(|p| + n)$$ 입니다.
(실제 reverse를 하지 않기 때문에 R이 많아도 효율적입니다.)

### 2. 공간복잡도 : $$O(n)$$
덱에 최대 n개의 원소를 저장하므로 $$O(n)$$ 공간이 필요합니다.
