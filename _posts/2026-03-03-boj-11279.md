## 문제 링크
[https://www.acmicpc.net/problem/11279](https://www.acmicpc.net/problem/11279)

## 문제 설명
최대 힙을 이용하여 다음 연산을 지원하는 프로그램을 작성한다.

- x가 자연수라면 x를 배열에 넣는다.
- x가 0이라면 배열에서 가장 큰 값을 출력하고 그 값을 배열에서 제거한다.
  - 배열이 비어있는데 0이 들어온 경우에는 0을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “가장 큰 값의 삽입/삭제/조회”를 빠르게 처리해야 하므로 **우선순위 큐(최대 힙)** 를 사용하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- C++ `priority_queue<int>`는 기본이 최대 힙이므로 별도 비교자 없이 그대로 사용한다.
- 입력이 자연수일 때:
  - 힙에 push 한다.
- 입력이 0일 때:
  - 힙이 비어있으면 0 출력
  - 비어있지 않으면 top(최대값)을 출력하고 pop 한다.
- 힙의 push/pop은 $$O(\log N)$$ 이므로 많은 연산도 효율적으로 처리할 수 있다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    priority_queue<int> pq;

    for (int i = 0; i < n; i++)
    {
        int x;
        cin >> x;

        if (x > 0)
            pq.push(x);
        else if (x == 0)
        {
            if (pq.empty())
            {
                cout << "0\n";
            }
            else
            {
                int maxVal = pq.top();
                pq.pop();
                cout << maxVal << '\n';
            }
        }
    }

    return 0;
}
```

---

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \log N)$$
총 N번의 연산이 들어오며, 각 연산에서 push/pop이 발생할 수 있습니다.
힙 연산은 한 번에 $$O(\log S)$$ (S는 힙 크기) 이고, 최악의 경우 S가 N까지 커질 수 있으므로 전체는 $$O(N \log N)$$ 수준입니다.

### 2. 공간복잡도 : $$O(N)$$
우선순위 큐에 입력된 값들이 저장될 수 있으므로, 최악의 경우 $$O(N)$$ 공간이 필요합니다.
