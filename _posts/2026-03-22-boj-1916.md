## 문제 링크
[https://www.acmicpc.net/problem/1916](https://www.acmicpc.net/problem/1916)

## 문제 설명
N개의 도시와 M개의 버스 정보가 주어진다. (방향 그래프)
각 버스는 출발 도시, 도착 도시, 비용을 가진다.
출발 도시에서 도착 도시까지 가는 최소 비용을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 간선 가중치(비용)가 모두 양수이므로, 한 정점에서 다른 정점까지의 최단 비용을 구하는 **다익스트라(Dijkstra)** 알고리즘으로 해결합니다.

### 1. 상태 정의 및 알고리즘 도출
- `v[u]` : u에서 갈 수 있는 (도착도시, 비용) 간선 목록(인접 리스트)
- `dist[x]` : 시작 도시에서 x까지의 현재까지 알려진 최소 비용 (초기값은 INF)

동작 방식
- 우선순위 큐에 (정점, 현재 비용)을 넣고, 비용이 작은 것부터 꺼낸다.
- 큐에서 꺼낸 값이 이미 dist보다 크면(더 비싼 경로) 무시한다. (가지치기)
- 현재 정점에서 갈 수 있는 간선을 모두 확인하며, 다음 비용 `nextCost`가 더 작다면 dist를 갱신하고 큐에 넣는다.
- 알고리즘 종료 후 `dist[도착]`이 최단 비용이다.

## 코드 (C++)
```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <climits>

using namespace std;

struct Edge
{
    int num;
    int cost;
};

struct compare
{
    bool operator()(Edge a, Edge b)
    {
        return a.cost > b.cost;
    }
};

int n, m;
int st, ed;
vector<int> dist;
vector<vector<Edge>> v;

void init()
{
    cin >> n >> m;
    v.resize(n + 1);
    dist.resize(n + 1, INT_MAX);
    for (int i = 0; i < m; ++i)
    {
        int from, to, cost;
        cin >> from >> to >> cost;

        v[from].push_back({to, cost});
    }
    cin >> st >> ed;
}

void dijkstra(int now)
{
    priority_queue<Edge, vector<Edge>, compare> pq;
    pq.push({now, 0});
    dist[now] = 0;

    while (!pq.empty())
    {
        Edge cur = pq.top();
        pq.pop();

        if (dist[cur.num] < cur.cost)
            continue;

        for (int i = 0; i < (int)v[cur.num].size(); ++i)
        {
            int nextCost = cur.cost + v[cur.num][i].cost;
            int tar = v[cur.num][i].num;

            if (nextCost < dist[tar])
            {
                dist[tar] = nextCost;
                pq.push({tar, nextCost});
            }
        }
    }
}

void solve()
{
    init();
    dijkstra(st);
    cout << dist[ed];
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O((N + M)\log N)$$
우선순위 큐를 사용하는 다익스트라는
간선 완화(relax) 과정이 최대 M번 발생하고, 각 push/pop이 $$\log N$$ 비용을 가집니다.
따라서 전체 시간복잡도는 $$O((N+M)\log N)$$ 로 볼 수 있습니다.

### 2. 공간복잡도 : $$O(N + M)$$
인접 리스트 `v`에 간선을 저장하는 데 $$O(N+M)$$,
거리 배열 `dist`가 $$O(N)$$ 공간을 사용합니다.
우선순위 큐도 최악의 경우 $$O(M)$$까지 원소가 들어갈 수 있어 전체는 $$O(N+M)$$ 입니다.
