## 문제 링크
[https://www.acmicpc.net/problem/1389](https://www.acmicpc.net/problem/1389)

## 문제 설명
N명의 사람이 있고, M개의 친구 관계(무방향 간선)가 주어진다.
각 사람 i에 대해 “케빈 베이컨 수”는 i에서 다른 모든 사람까지의 최단 거리 합이다.
케빈 베이컨 수가 가장 작은 사람의 번호를 출력한다.
(여러 명이면 번호가 가장 작은 사람)

---

## 풀이 전략 (Approach)
이 문제는 모든 정점에서 다른 모든 정점까지의 최단 거리 합을 구해야 하므로,
각 정점에서 BFS를 수행하는 방식으로 해결할 수 있습니다. (가중치가 1인 무방향 그래프)

### 1. 상태 정의 및 알고리즘 도출
- `adj[u]` : u와 연결된 정점 목록(인접 리스트)
- `visited[x]` : 시작 정점에서 x까지의 최단 거리 (미방문은 -1)

동작 방식
- i를 1부터 N까지 돌며, i를 시작점으로 BFS를 수행한다.
- BFS가 끝나면 `visited[1..N]`의 합이 i의 케빈 베이컨 수가 된다.
- 그 합이 최소가 되는 i를 정답으로 갱신한다.
- 같은 값이 나와도 “번호가 작은 사람”이 우선이므로, `<` 비교만 사용하면 자동으로 가장 작은 번호가 남는다.

## 코드 (C++)
```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <algorithm>
#include <climits>

using namespace std;

int n, m;
int min_bacon = INT_MAX;
vector<int> visited;
vector<int> bacon;
int ans = 1;
vector<vector<int>> adj;

void init()
{
    cin >> n >> m;
    adj.assign(n + 1, vector<int>());
    visited.assign(n + 1, -1);
    bacon.assign(n + 1, 0);

    for (int i = 0; i < m; ++i)
    {
        int from, to;
        cin >> from >> to;
        adj[from].push_back(to);
        adj[to].push_back(from);
    }
}

void bfs(int now)
{
    queue<int> q;
    q.push(now);
    visited[now] = 0;

    while (!q.empty())
    {
        int cur = q.front();
        q.pop();

        for (int i = 0; i < (int)adj[cur].size(); ++i)
        {
            int nxt = adj[cur][i];

            if (visited[nxt] != -1)
                continue;

            q.push(nxt);
            visited[nxt] = visited[cur] + 1;
        }
    }
}

void solve()
{
    init();

    for (int i = 1; i <= n; i++)
    {
        visited.assign(n + 1, -1);
        bfs(i);

        bacon[i] = 0;
        for (int j = 1; j <= n; j++)
            bacon[i] += visited[j];

        if (bacon[i] < min_bacon) {
            min_bacon = bacon[i];
            ans = i;
        }
    }

    cout << ans;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times (N + M))$$
정점 i마다 BFS를 한 번 수행합니다.
BFS 한 번은 정점과 간선을 각각 최대 한 번씩 확인하므로 $$O(N+M)$$ 입니다.
이를 N번 반복하므로 전체 시간복잡도는 $$O(N(N+M))$$ 입니다.

### 2. 공간복잡도 : $$O(N + M)$$
인접 리스트 `adj`가 $$O(N+M)$$ 공간을 사용하고,
거리 배열 `visited`가 $$O(N)$$,
BFS 큐도 최악의 경우 $$O(N)$$ 까지 커질 수 있으므로 전체 공간복잡도는 $$O(N+M)$$ 입니다.
