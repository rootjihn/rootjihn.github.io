## 문제 링크
[https://www.acmicpc.net/problem/1012](https://www.acmicpc.net/problem/1012)

## 문제 설명
배추밭에서 배추가 심어져 있는 위치들이 주어질 때, 서로 인접(상하좌우)한 배추들은 하나의 그룹을 이룬다.
각 테스트 케이스마다 필요한 지렁이의 수(= 배추 그룹의 개수)를 출력한다.

- 배추밭 크기: M(가로) × N(세로)
- 배추 위치 개수: K

---

## 풀이 전략 (Approach)
이 문제는 격자에서 인접한 배추(1) 덩어리의 개수를 세는 **그래프 탐색(BFS/DFS)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`visited[y][x]`를 (y, x) 칸을 방문했는지 여부라고 정의하면,

- 전체 칸을 돌면서 아직 방문하지 않은 배추(값 1)를 찾는다.
- 그 칸에서 BFS를 시작하여 같은 연결 요소(배추 덩어리)에 속한 모든 배추를 방문 처리한다.
- BFS를 시작한 횟수가 곧 배추 덩어리(연결 요소)의 개수이므로, 이를 카운트하면 정답이다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

struct Point { int y; int x; };

int m, n, k;
vector<vector<int>> MAP, visited;
int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

void bfs(Point now)
{
    queue<Point> q;
    q.push(now);
    visited[now.y][now.x] = 1;

    while (!q.empty())
    {
        Point cp = q.front();
        q.pop();

        for (int i = 0; i < 4; i++)
        {
            Point np = { cp.y + dy[i], cp.x + dx[i] };

            if (np.y < 0 || np.x < 0 || np.y >= n || np.x >= m) continue;
            if (MAP[np.y][np.x] == 0) continue;
            if (visited[np.y][np.x] == 1) continue;

            visited[np.y][np.x] = 1;
            q.push(np);
        }
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--)
    {
        cin >> m >> n >> k;

        MAP.assign(n, vector<int>(m, 0));
        visited.assign(n, vector<int>(m, 0));

        for (int i = 0; i < k; i++)
        {
            int x, y;
            cin >> x >> y;
            MAP[y][x] = 1;
        }

        int cnt = 0;

        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < m; j++)
            {
                if (MAP[i][j] == 1 && visited[i][j] == 0)
                {
                    cnt++;
                    bfs({ i, j });
                }
            }
        }

        cout << cnt << "\n";
    }
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times M)$$
각 칸은 방문 처리 후 최대 한 번만 BFS 큐에 들어가며,
각 칸에서 4방향만 확인하므로 전체 연산량은 칸 수에 비례합니다.
따라서 시간복잡도는 $$O(NM)$$ 입니다.

### 2. 공간복잡도 : $$O(N \times M)$$
지도 `MAP`과 방문 배열 `visited`가 각각 $$O(NM)$$ 공간을 사용하고,
최악의 경우 BFS 큐도 많은 칸을 담을 수 있어 $$O(NM)$$ 수준의 공간이 필요합니다.
