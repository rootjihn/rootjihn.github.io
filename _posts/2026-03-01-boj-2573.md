## 문제 링크
[https://www.acmicpc.net/problem/2573](https://www.acmicpc.net/problem/2573)

## 문제 설명
N×M 격자에서 0은 바다, 양수는 빙산의 높이를 의미한다.
1년이 지날 때마다 빙산은 상하좌우에 인접한 바다(0)의 개수만큼 높이가 감소한다(0 미만으로 내려가진 않음).
빙산이 두 덩어리 이상으로 분리되는 최초의 시간을 출력하고,
끝까지 분리되지 않고 모두 녹으면 0을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “매년 빙산을 녹이는 시뮬레이션”과 “현재 빙산 덩어리(연결 요소) 개수 확인”을 반복하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- `map[y][x]` : (y, x)의 빙산 높이(0이면 바다)
- `visited_num[y][x]` : 덩어리 개수 확인(BFS) 시 방문 여부
- 매년 수행할 작업은 2가지입니다.

(1) 덩어리 개수 세기 (BFS)
- 전체 칸을 돌면서 아직 방문하지 않은 빙산 칸(>0)을 만나면 BFS를 시작한다.
- BFS 1번이 연결된 빙산 덩어리 1개를 전부 방문 처리하므로, BFS 시작 횟수가 덩어리 개수 `num`이 된다.

(2) 빙산 녹이기 (동시 갱신)
- 각 빙산 칸에 대해 인접한 바다(0)의 개수를 세어 그만큼 높이가 줄어든다.
- “동시에 녹아야” 하므로, 먼저 `melt` 배열에 감소량을 저장해두고 한 번에 반영한다.

종료 조건
- `num == 0` : 빙산이 전부 녹았는데 분리된 적이 없으므로 0 출력
- `num >= 2` : 두 덩어리 이상으로 처음 분리된 해(year)를 출력

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

struct Point
{
    int y;
    int x;
};

int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

int n, m;
vector<vector<int>> map;
vector<vector<int>> visited_num;
int num;
int year;

void bfs_num(Point st)
{
    queue<Point> q;
    visited_num[st.y][st.x] = 1;
    q.push(st);

    while (!q.empty())
    {
        Point cp = q.front();
        q.pop();
        for (int i = 0; i < 4; i++)
        {
            Point now = { cp.y + dy[i], cp.x + dx[i] };

            if (now.y < 0 || now.y >= n || now.x < 0 || now.x >= m) continue;
            if (visited_num[now.y][now.x]) continue;
            if (map[now.y][now.x] == 0) continue;

            visited_num[now.y][now.x] = 1;
            q.push(now);
        }
    }
}

void func_melt()
{
    vector<vector<int>> melt(n, vector<int>(m, 0));

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (map[i][j] == 0) continue;

            int sea = 0;
            for (int d = 0; d < 4; d++)
            {
                int ny = i + dy[d];
                int nx = j + dx[d];

                if (ny < 0 || ny >= n || nx < 0 || nx >= m) continue;
                if (map[ny][nx] == 0) sea++;
            }
            melt[i][j] = sea;
        }
    }

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            map[i][j] = max(0, map[i][j] - melt[i][j]);
        }
    }
}

int main()
{
    ios_base::sync_with_stdio(false); cin.tie(NULL);

    cin >> n >> m;
    map.assign(n, vector<int>(m, 0));
    visited_num.assign(n, vector<int>(m, 0));

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> map[i][j];
        }
    }

    year = 0;

    while (true)
    {
        num = 0;
        visited_num.assign(n, vector<int>(m, 0));

        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < m; j++)
            {
                if (map[i][j] != 0 && visited_num[i][j] == 0)
                {
                    num++;
                    bfs_num({ i, j });
                }
            }
        }

        if (num == 0)
        {
            cout << 0;
            return 0;
        }

        if (num >= 2)
        {
            cout << year;
            return 0;
        }

        func_melt();
        year++;
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(Y \times N \times M)$$
매년
- 덩어리 개수 확인을 위해 격자를 한 번 훑고(BFS 포함) 전체적으로 $$O(NM)$$,
- 녹이는 과정에서 `melt` 계산과 반영을 위해 $$O(NM)$$
이 필요합니다.
따라서 한 해에 $$O(NM)$$이고, 분리되거나 모두 녹을 때까지의 연수를 Y라고 하면 전체는 $$O(Y \cdot NM)$$ 입니다.

### 2. 공간복잡도 : $$O(N \times M)$$
`map`, `visited_num`, `melt`가 각각 $$O(NM)$$ 공간을 사용합니다.
BFS 큐도 최악의 경우 $$O(NM)$$ 까지 커질 수 있으므로 전체 공간은 $$O(NM)$$ 입니다.
