## 문제 링크
[https://www.acmicpc.net/problem/1654](https://www.acmicpc.net/problem/1654)

## 문제 설명
길이가 서로 다른 K개의 랜선이 있다. 이 랜선을 같은 길이의 랜선 N개 이상으로 만들려고 한다.
랜선을 자를 수 있는 최대 길이를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “조건을 만족하는 길이 중 최댓값”을 찾는 형태이므로 **이분 탐색(파라메트릭 서치)** 으로 해결하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
랜선 길이를 L로 잘랐을 때 만들 수 있는 랜선 개수를 `cnt(L)`이라고 하면,

- `cnt(L) = sum(LAN[i] / L)` 로 계산된다.
- L이 커질수록 만들 수 있는 개수는 줄어드므로 `cnt(L)`은 단조 감소한다.
- 따라서 `cnt(L) >= N`을 만족하는 L의 최댓값을 이분 탐색으로 찾을 수 있다.

이분 탐색 범위는 다음과 같이 잡는다.
- `left = 1` (길이 0은 불가능)
- `right = maxL` (가장 긴 랜선 길이)

중간값 `mid`에 대해:
- `cnt(mid) >= N`이면 조건을 만족하므로 더 큰 길이를 시도하기 위해 `left = mid + 1`, 정답 후보 `ans = mid` 갱신
- `cnt(mid) < N`이면 부족하므로 `right = mid - 1`

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <climits>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int k, n;
    cin >> k >> n;
    vector<int> LAN(k, 0);
    int maxL = 0;

    for (int i = 0; i < k; i++)
    {
        cin >> LAN[i];
        if (maxL < LAN[i])
            maxL = LAN[i];
    }

    long long left = 1, right = maxL;
    long long ans = INT_MAX;

    while (left <= right)
    {
        long long mid = left + (right - left) / 2;

        int num = 0;

        for (int i = 0; i < k; i++)
        {
            num += LAN[i] / mid;
        }

        if (num >= n)
        {
            left = mid + 1;
            ans = mid;
        }
        else
        {
            right = mid - 1;
        }
    }

    cout << ans;

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(K \log L)$$
이분 탐색은 길이 범위(1 ~ maxL)에서 진행되므로 반복 횟수가 $$O(\log L)$$ 입니다. (여기서 $$L = maxL$$)
각 반복마다 K개의 랜선을 순회하며 개수를 계산하므로 $$O(K)$$ 가 걸립니다.
따라서 전체 시간복잡도는 $$O(K \log L)$$ 입니다.

### 2. 공간복잡도 : $$O(K)$$
랜선 길이를 저장하는 배열 `LAN`이 $$O(K)$$ 공간을 사용합니다.
