## 문제 링크
[https://www.acmicpc.net/problem/11724](https://www.acmicpc.net/problem/11724)

## 문제 설명
방향 없는 그래프가 주어졌을 때, 연결 요소(Connected Component)의 개수를 구하는 프로그램을 작성하시오.

---

## 풀이 전략 (Approach)
이 문제는 그래프에서 **연결 요소의 개수**를 세는 기본 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`visited[i]`를 정점 i를 방문했는지 여부라고 정의하면,

- 아직 방문하지 않은 정점 i를 하나 찾는다.
- i에서 DFS를 수행하여 i와 같은 연결 요소에 속한 모든 정점을 방문 처리한다.
- DFS를 한 번 시작할 때마다 연결 요소를 1개 전부 방문한 것이므로, DFS 시작 횟수를 세면 연결 요소의 개수가 된다.

DFS/BFS 둘 다 연결된 정점들을 한 번에 쭉 방문 처리할 수 있으므로 둘 다 가능하지만, 여기서는 DFS로 구현한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, m, ans;
vector<vector<int>> adj;
vector<int> visited;

void init()
{
    cin >> n >> m;
    ans = 0;
    adj.assign(n + 1, {});
    visited.assign(n + 1, 0);
    for (int i = 0; i < m; i++)
    {
        int from, to;
        cin >> from >> to;
        adj[from].push_back(to);
        adj[to].push_back(from);
    }
}

void dfs(int now)
{
    for (int i = 0; i < adj[now].size(); i++)
    {
        int next = adj[now][i];
        if (visited[next] == 1)
            continue;

        visited[next] = 1;
        dfs(next);
    }
}

void solve()
{
    init();
    for (int i = 1; i < n + 1; i++)
    {
        if (visited[i] == 0)
        {
            visited[i] = 1;
            dfs(i);
            ans++;
        }
    }

    cout << ans << "\n";
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N + M)$$
모든 정점은 방문 체크 과정에서 최대 1번 방문 처리되고(O(N)),
DFS 과정에서 각 간선은 인접 리스트를 따라가며 최대 2번(무방향이므로 양쪽 리스트) 확인하므로 전체가 O(M)입니다.
따라서 총 시간복잡도는 $$O(N+M)$$ 입니다.

### 2. 공간복잡도 : $$O(N + M)$$
인접 리스트에 간선 정보를 저장하는 데 $$O(N+M)$$ 공간이 필요하고,
방문 배열 `visited`가 $$O(N)$$ 이므로 전체 공간복잡도는 $$O(N+M)$$ 입니다.
