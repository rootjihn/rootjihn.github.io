## 문제 링크
[https://www.acmicpc.net/problem/11659](https://www.acmicpc.net/problem/11659)

## 문제 설명
N개의 수가 주어졌을 때, i번째 수부터 j번째 수까지의 합을 구하는 프로그램을 작성하시오.
총 M개의 구간 합 질의가 주어진다.

---

## 풀이 전략 (Approach)
이 문제는 여러 번의 구간 합을 빠르게 처리하기 위해 **누적 합(Prefix Sum)** 을 사용하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`prefix[i]`를 1번부터 i번까지의 합이라고 정의하면,

- `prefix[i] = prefix[i-1] + arr[i]` 로 누적 합을 미리 만들어 둔다.
- 구간 [a, b]의 합은 1~b 합에서 1~(a-1) 합을 빼면 되므로 다음과 같다.

$$
sum(a,b) = prefix[b] - prefix[a-1]
$$

이렇게 하면 각 질의를 O(1)에 처리할 수 있다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<long long> prefix(n + 1, 0); // prefix[0]=0
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
    }

    while (m--) {
        int a, b;
        cin >> a >> b;
        cout << (prefix[b] - prefix[a - 1]) << "\n";
    }

    return 0;
}
```

---

## 복잡도 분석
### 1. 시간복잡도 : $$O(N + M)$$
누적 합 배열을 만드는 데 $$O(N)$$,
각 질의는 `prefix[b] - prefix[a-1]` 한 번의 계산으로 $$O(1)$$ 이므로,
총 M개의 질의 처리 시간은 $$O(M)$$ 입니다.
따라서 전체 시간복잡도는 $$O(N+M)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
누적 합 배열 `prefix`가 크기 N+1로 필요하므로 $$O(N)$$ 공간을 사용합니다.
