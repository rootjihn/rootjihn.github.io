## 문제 링크
[https://www.acmicpc.net/problem/14500](https://www.acmicpc.net/problem/14500)

## 문제 설명
N×M 크기의 종이에 숫자가 적혀 있다.
테트로미노(4칸으로 이루어진 도형)를 종이에 놓았을 때, 테트로미노가 놓인 칸의 합의 최댓값을 구한다.
테트로미노는 회전/대칭이 가능하며, 종이 밖으로 나가면 안 된다.

---

## 풀이 전략 (Approach)
이 문제는 모든 테트로미노 배치를 확인해야 하므로 **완전탐색**이 필요합니다.
일반적인 테트로미노(ㅁ, ㄴ, ㄱ, ㅡ 등)는 DFS로 4칸을 연속으로 선택해 만들 수 있지만,
'ㅗ' 모양(ㅗ/ㅜ/ㅏ/ㅓ)만은 DFS 경로로 만들기 어렵기 때문에 별도로 처리합니다.

### 1. 상태 정의 및 알고리즘 도출
- `visited[y][x]` : DFS로 4칸을 선택할 때 중복 방문을 막기 위한 방문 배열
- DFS 탐색:
  - 시작 칸에서 상하좌우로 이동하며 4칸을 선택한다.
  - 선택한 4칸의 합(cost)을 갱신하며 최댓값을 업데이트한다.
- 예외(ㅗ 모양) 처리:
  - 중심 칸을 기준으로 최대 4방향 이웃 칸 중 3개를 선택하는 형태이므로,
    각 칸에서 “중심 + 이웃 3개”의 합을 직접 계산한다.
  - 이웃이 3개 미만이면 불가능, 3개면 그대로 합, 4개면 한 방향을 하나씩 빼보며 최대값을 갱신한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

struct Point
{
    int y, x;
};

int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

int n, m;
int maxVal;
vector<vector<int>> board;
vector<vector<bool>> visited;

void init()
{
    cin >> n >> m;
    board.assign(n, vector<int>(m, 0));
    visited.assign(n, vector<bool>(m, false));

    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < m; ++j)
        {
            cin >> board[i][j];
        }
    }
}

void dfs(Point st, int cost, int cnt)
{
    if (cnt == 4)
    {
        maxVal = max(maxVal, cost);
        return;
    }

    for (int i = 0; i < 4; ++i)
    {
        Point np = { st.y + dy[i], st.x + dx[i] };

        if (np.y < 0 || np.x < 0 || np.y >= n || np.x >= m)
            continue;
        if (visited[np.y][np.x])
            continue;

        visited[np.y][np.x] = true;
        dfs(np, cost + board[np.y][np.x], cnt + 1);
        visited[np.y][np.x] = false;
    }
}

void checkExtra(Point st)
{
    int wing[4];
    int cnt = 0;
    int sum = board[st.y][st.x];

    for (int i = 0; i < 4; ++i)
    {
        Point np = { st.y + dy[i], st.x + dx[i] };

        if (np.y < 0 || np.x < 0 || np.y >= n || np.x >= m)
            continue;

        wing[cnt++] = board[np.y][np.x];
        sum += board[np.y][np.x];
    }

    if (cnt < 3)
        return;

    if (cnt == 3)
    {
        maxVal = max(maxVal, sum);
        return;
    }

    for (int i = 0; i < 4; ++i)
    {
        maxVal = max(maxVal, sum - wing[i]);
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();

    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < m; ++j)
        {
            visited[i][j] = true;
            dfs({ i, j }, board[i][j], 1);
            visited[i][j] = false;

            checkExtra({ i, j });
        }
    }

    cout << maxVal;
    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times M)$$ (상수배 큰 완전탐색)
각 칸을 시작점으로 DFS를 수행하며, 깊이가 4로 고정이라 탐색 분기 수는 상수 수준입니다.
또한 각 칸에서 ㅗ 모양 체크도 최대 4방향만 확인하는 상수 시간입니다.
따라서 전체 시간은 격자 칸 수에 비례하여 $$O(NM)$$로 볼 수 있습니다. (실제로는 상수배가 큼)

### 2. 공간복잡도 : $$O(N \times M)$$
입력 보드 `board`와 방문 배열 `visited`가 $$O(NM)$$ 공간을 사용합니다.
DFS 재귀 깊이는 최대 4이므로 호출 스택은 상수 공간입니다.
