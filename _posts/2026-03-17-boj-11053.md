## 문제 링크
[https://www.acmicpc.net/problem/11053](https://www.acmicpc.net/problem/11053)

## 문제 설명
수열 A가 주어졌을 때, 가장 긴 증가하는 부분 수열(LIS)의 길이를 출력한다.
부분 수열은 원래 수열에서 일부 원소를 골라 순서를 유지한 수열이다.

---

## 풀이 전략 (Approach)
이 문제는 전형적인 **Dynamic Programming(DP)** 문제입니다.
각 위치를 “마지막 원소로 갖는 LIS 길이”로 정의하면, 이전 원소들과 비교해서 값을 갱신할 수 있습니다.

### 1. 상태 정의 및 점화식 도출
`dp[i]`를 “i번째 원소 a[i]를 마지막으로 하는 가장 긴 증가하는 부분 수열의 길이”라고 정의하면,

- 기본값은 자기 자신만 선택하는 경우이므로 `dp[i] = 1`
- i보다 앞에 있는 j(0 ≤ j < i) 중에서 a[j] < a[i]인 원소를 이어 붙일 수 있다.
  - 이때 후보는 `dp[j] + 1` 이다.

따라서 점화식은 다음과 같습니다.

$$
dp[i] = 1 + \max(dp[j]) \quad (0 \le j < i,\ a[j] < a[i])
$$

정답은 모든 i에 대해 `dp[i]`의 최댓값이다.

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> a(n);
    for (int i = 0; i < n; ++i)
    {
        cin >> a[i];
    }

    vector<int> dp(n, 1);

    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < i; ++j)
        {
            if (a[j] < a[i])
            {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
    }

    cout << *max_element(dp.begin(), dp.end());
    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N^2)$$
각 i에 대해 i 이전의 모든 j를 확인하므로 이중 반복문이 됩니다.
따라서 시간복잡도는 $$O(N^2)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
수열 a와 dp 배열이 각각 크기 N이므로 $$O(N)$$ 공간을 사용합니다.
