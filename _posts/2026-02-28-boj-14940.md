## 문제 링크
[https://www.acmicpc.net/problem/14940](https://www.acmicpc.net/problem/14940)

## 문제 설명
n×m 크기의 지도에서 각 칸은 다음 의미를 가진다.

- 0: 갈 수 없는 땅
- 1: 갈 수 있는 땅
- 2: 목표 지점

목표 지점(값 2)에서 출발하여 각 칸까지의 최단 거리를 구해 출력한다.

- 갈 수 있는 땅(1)인데 도달할 수 없는 칸은 -1 출력
- 갈 수 없는 땅(0)은 0 출력
- 목표 지점(2)은 0 출력

---

## 풀이 전략 (Approach)
이 문제는 격자에서 최단거리를 구하는 전형적인 **그래프 탐색(BFS)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`visited[y][x]`를 (y, x) 칸까지의 “거리 정보”를 저장하는 배열이라고 두면,

- 시작점(값이 2인 칸)에서 BFS를 시작한다.
- BFS는 가중치가 모두 동일(한 칸 이동 비용 1)일 때 최단거리를 보장한다.
- 갈 수 있는 땅(값 1 또는 2)만 이동할 수 있고, 값 0인 칸은 이동하지 않는다.
- BFS 도중 `visited[ny][nx] = visited[now.y][now.x] + 1`로 저장하면 거리(레벨)가 기록된다.
- 출력 시:
  - `board[i][j] > 0`인데 `visited[i][j] == 0`이면 도달 불가이므로 -1
  - `board[i][j] == 0`이면 원래 갈 수 없는 땅이므로 0
  - 그 외에는 방문 값이 1부터 시작했으므로 `visited[i][j] - 1`이 실제 최단거리

## 코드 (C++)
```cpp
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

struct Point
{
    int y, x;
};

int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

Point st;
int n, m;
vector<vector<int>> board;
vector<vector<int>> visited;

void init()
{
    cin >> n >> m;
    board.assign(n, vector<int>(m, 0));
    visited.assign(n, vector<int>(m, 0));
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> board[i][j];
            if (board[i][j] == 2)
                st = { i,j };
        }
    }
}

void bfs()
{
    queue<Point> q;
    q.push(st);
    visited[st.y][st.x] = 1;

    while (!q.empty())
    {
        Point now = q.front();
        q.pop();

        for (int i = 0; i < 4; i++)
        {
            int ny = now.y + dy[i];
            int nx = now.x + dx[i];

            if (ny < 0 || nx < 0 || ny >= n || nx >= m)
                continue;

            if (visited[ny][nx] > 0)
                continue;

            if (board[ny][nx] == 0)
                continue;

            q.push({ ny,nx });
            visited[ny][nx] = visited[now.y][now.x] + 1;
        }
    }
}

void solve()
{
    init();
    bfs();

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (board[i][j] > 0 && visited[i][j] == 0)
                cout << -1 << " ";
            else
            {
                if (visited[i][j] == 0)
                    cout << visited[i][j] << " ";
                else
                    cout << visited[i][j] - 1 << " ";
            }
        }
        cout << "\n";
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times M)$$
BFS에서 각 칸은 최대 한 번 큐에 들어가고,
각 칸에서 4방향만 확인하므로 전체 연산량은 칸 수에 비례합니다.
따라서 시간복잡도는 $$O(NM)$$ 입니다.

### 2. 공간복잡도 : $$O(N \times M)$$
지도 `board`와 거리 배열 `visited`가 각각 $$O(NM)$$ 이고,
최악의 경우 큐에도 많은 칸이 들어갈 수 있어 $$O(NM)$$ 수준의 추가 공간이 필요합니다.
따라서 공간복잡도는 $$O(NM)$$ 입니다.
