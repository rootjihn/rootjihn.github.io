## 문제 링크
[https://www.acmicpc.net/problem/11725](https://www.acmicpc.net/problem/11725)

## 문제 설명
루트가 1인 트리가 주어진다. 각 노드의 부모를 구해서 2번 노드부터 N번 노드까지 출력한다.
트리는 N개의 정점과 N-1개의 간선으로 이루어진 연결 그래프이며 사이클이 없다.

---

## 풀이 전략 (Approach)
이 문제는 루트(1)에서 트리를 한 번 탐색하면서 “부모-자식 관계”를 정하면 됩니다.
루트에서 DFS/BFS를 수행하며, 방문하지 않은 이웃을 자식으로 보고 부모를 기록합니다.

### 1. 상태 정의 및 알고리즘 도출
- `graph[u]` : u와 연결된 정점 목록(인접 리스트)
- `visited[u]` : u를 방문했는지 여부
- `parent[u]` : u의 부모 정점 번호

동작 방식
- 1번 노드를 루트로 DFS를 시작한다.
- 현재 노드 now의 이웃 nxt를 보면서 아직 방문하지 않은 노드라면,
  - `parent[nxt] = now` 로 부모를 기록하고
  - nxt로 DFS를 진행한다.
- 탐색이 끝나면 2번부터 N번까지 `parent[i]`를 출력한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

vector<vector<int>> graph;
vector<int> parent;
vector<bool> visited;

int n;

void init()
{
    cin >> n;
    graph.assign(n + 1, vector<int>());
    parent.assign(n + 1, 0);
    visited.assign(n + 1, false);

    for (int i = 0; i < n - 1; ++i)
    {
        int a, b;
        cin >> a >> b;

        graph[a].push_back(b);
        graph[b].push_back(a);
    }
}

void dfs(int now)
{
    visited[now] = true;

    for (int nxt : graph[now])
    {
        if (!visited[nxt])
        {
            parent[nxt] = now;
            dfs(nxt);
        }
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    dfs(1);

    for (int i = 2; i <= n; ++i)
    {
        cout << parent[i] << "\n";
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N)$$
트리는 간선이 N-1개이고, DFS에서 각 정점과 간선을 한 번씩만 처리합니다.
따라서 시간복잡도는 $$O(N)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
인접 리스트 `graph`가 $$O(N)$$ 수준(정확히는 $$O(N+ (N-1))$$),
`parent`, `visited` 배열이 $$O(N)$$ 공간을 사용합니다.
DFS 재귀 호출 스택도 최악의 경우 $$O(N)$$ 까지 깊어질 수 있으므로 전체도 $$O(N)$$ 입니다.
