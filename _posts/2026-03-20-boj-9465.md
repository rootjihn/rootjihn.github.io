## 문제 링크
[https://www.acmicpc.net/problem/9465](https://www.acmicpc.net/problem/9465)

## 문제 설명
2행 N열 스티커가 있고 각 칸의 점수가 주어진다.
스티커를 하나 떼면 상하좌우로 인접한 스티커는 사용할 수 없다.
얻을 수 있는 점수의 최댓값을 출력한다. (여러 테스트케이스)

---

## 풀이 전략 (Approach)
이 문제는 “열 단위로 진행하면서, 특정 위치 스티커를 선택했을 때의 최대 점수”를 누적하는 전형적인 **Dynamic Programming(DP)** 문제입니다.

### 1. 상태 정의 및 점화식 도출
`dp[r][i]`를 i번째 열까지 고려했을 때, i번째 열에서 r행(0 또는 1) 스티커를 선택한 경우의 최대 점수라고 정의합니다.
(코드에서는 1-index로 맞추기 위해 dp의 열 인덱스를 1~N으로 사용)

- i번째 열의 위쪽(0행)을 선택하면, i-1열에서는 아래쪽(1행)만 가능하고
  i-2열까지는 어떤 상태든 가능하므로 다음과 같이 갱신할 수 있습니다.

$$
dp[0][i] = \max(dp[1][i-1],\ dp[1][i-2]) + sticker[0][i]
$$

- i번째 열의 아래쪽(1행)을 선택하는 경우도 대칭적으로

$$
dp[1][i] = \max(dp[0][i-1],\ dp[0][i-2]) + sticker[1][i]
$$

기저 조건(첫 열):
- `dp[0][1] = sticker[0][0]`
- `dp[1][1] = sticker[1][0]`
- `dp[*][0] = 0`

정답:
- `max(dp[0][N], dp[1][N])`

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int n;
vector<vector<int>> dp;
vector<vector<int>> sticker;

void init()
{
    cin >> n;
    dp.assign(2, vector<int>(n + 1, 0));
    sticker.assign(2, vector<int>(n, 0));
    for (int i = 0; i < 2; ++i)
    {
        for (int j = 0; j < n; ++j)
        {
            cin >> sticker[i][j];
        }
    }
}

void solve()
{
    dp[0][0] = dp[1][0] = 0;
    dp[0][1] = sticker[0][0];
    dp[1][1] = sticker[1][0];

    for (int i = 2; i <= n; ++i)
    {
        dp[0][i] = max(dp[1][i - 1], dp[1][i - 2]) + sticker[0][i - 1];
        dp[1][i] = max(dp[0][i - 1], dp[0][i - 2]) + sticker[1][i - 1];
    }

    cout << max(dp[0][n], dp[1][n]) << "\n";
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--)
    {
        init();
        solve();
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N)$$
각 테스트케이스마다 i=2..N에 대해 상수 시간으로 dp를 갱신합니다.
따라서 시간복잡도는 $$O(N)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
dp 배열이 2×(N+1), sticker 배열이 2×N 크기이므로 $$O(N)$$ 공간을 사용합니다.
