## 문제 링크
[https://www.acmicpc.net/problem/2667](https://www.acmicpc.net/problem/2667)

## 문제 설명
N×N 지도가 주어지고, 1은 집이 있는 곳, 0은 집이 없는 곳이다.
상하좌우로 연결된 집들은 하나의 단지(연결 요소)를 이룬다.

- 단지의 개수
- 각 단지 내 집의 수(오름차순)

를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 격자에서 연결된 1의 덩어리(단지)를 찾아 크기를 세는 **그래프 탐색(BFS/DFS)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`visited[y][x]`를 (y, x) 칸을 방문했는지 여부라고 정의하면,

- 전체 격자를 돌며 아직 방문하지 않은 집(값 1)을 찾는다.
- 그 칸에서 BFS를 시작하여 같은 단지에 속한 모든 집을 방문 처리한다.
- BFS를 한 번 시작할 때마다 단지 개수는 1 증가하고,
  BFS 중 방문한 집의 개수를 세면 해당 단지의 크기가 된다.
- 모든 BFS가 끝나면 단지 크기 배열을 정렬하여 출력한다.

## 코드 (C++)
```cpp
#include <iostream> 
#include <vector>
#include <queue>
#include <string>
#include <algorithm>

using namespace std;

struct Point
{
    int y, x;
};

int dy[4] = {-1, 1, 0, 0};
int dx[4] = {0, 0, -1, 1};

int n;
int cnt = 1;
vector<vector<int>> board;
vector<vector<int>> visited;
vector<int> apt_num;

void init()
{
    cin >> n;
    board.assign(n, vector<int>(n, 0));
    visited.assign(n, vector<int>(n, 0));
    apt_num.clear();

    for (int i = 0; i < n; ++i)
    {
        string s;
        cin >> s;
        for (int j = 0; j < n; ++j)
        {
            board[i][j] = s[j] - '0';
        }
    }
}

void bfs(Point st)
{
    int aptN = 1;
    queue<Point> q;
    q.push(st);
    visited[st.y][st.x] = 1;
    board[st.y][st.x] = cnt;

    while (!q.empty())
    {
        Point cp = q.front();
        q.pop();
        for (int i = 0; i < 4; ++i)
        {
            Point np = {cp.y + dy[i], cp.x + dx[i]};

            if (np.y < 0 || np.x < 0 || np.y >= n || np.x >= n)
                continue;
            if (board[np.y][np.x] == 0)
                continue;
            if (visited[np.y][np.x] == 1)
                continue;

            visited[np.y][np.x] = 1;
            board[np.y][np.x] = cnt;
            aptN++;
            q.push(np);
        }
    }
    cnt++;
    apt_num.push_back(aptN);
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    for (int i = 0; i < n; ++i)
    {
        for (int j = 0; j < n; ++j)
        {
            if (board[i][j] == 1 && visited[i][j] == 0)
            {
                bfs({i, j});
            }
        }
    }

    sort(apt_num.begin(), apt_num.end());

    cout << cnt - 1 << "\n";
    for(int x : apt_num)
    {
        cout << x << "\n";
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times N)$$
BFS에서 각 칸은 최대 한 번 방문되고,
각 방문에서 4방향만 확인하므로 탐색 비용은 $$O(N^2)$$ 입니다.
탐색 후 단지 크기 배열을 정렬하는 비용이 $$O(C \log C)$$ (C는 단지 개수)인데,
C는 최대 $$N^2$$ 이지만 보통 탐색 비용 $$O(N^2)$$ 가 지배적입니다.
따라서 전체 시간복잡도는 $$O(N^2)$$ 로 볼 수 있습니다.

### 2. 공간복잡도 : $$O(N \times N)$$
지도 `board`, 방문 배열 `visited`가 각각 $$O(N^2)$$ 공간을 사용합니다.
BFS 큐도 최악의 경우 $$O(N^2)$$ 까지 커질 수 있으므로 전체 공간복잡도는 $$O(N^2)$$ 입니다.
