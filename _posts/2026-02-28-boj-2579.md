## 문제 링크
> [https://www.acmicpc.net/problem/2579](https://www.acmicpc.net/problem/2579)

## 문제 설명
계단 오르기 게임은 계단 아래 시작점부터 계단 꼭대기에 위치한 도착점까지 가는 게임이다.

**<규칙>**
1. 계단은 한 번에 **1계단** 또는 **2계단**씩 오를 수 있다.
2. 연속된 **3개의 계단을 모두 밟아서는 안 된다.** (시작점은 포함 안 함)
3. **마지막 도착 계단은 반드시 밟아야 한다.**

이 규칙을 지키면서 얻을 수 있는 **점수의 최댓값**을 구하시오.

---

## 풀이 전략
이 문제는 **Dynamic Programming (DP)**로 해결해야 합니다.
`dp[i]`를 **'i번째 계단에 도착했을 때 얻을 수 있는 점수의 최댓값'**으로 정의합니다.

마지막 계단(`i`)에 도착하는 방법은 딱 **두 가지**밖에 없습니다. (연속 3계단 금지 규칙 때문)

### 경우의 수 1: 2칸 점프해서 도착한 경우
직전 칸(`i-1`)을 밟지 않고, 전전 칸(`i-2`)에서 바로 올라온 경우입니다.
* **점화식:** `dp[i-2] + score[i]`
* 이 경우 연속 밟기 규칙에 걸릴 일이 없습니다.

### 경우의 수 2: 1칸 올라와서 도착한 경우
직전 칸(`i-1`)을 밟고 올라온 경우입니다.
이때 중요한 점은, **`i-1`번째 계단에는 반드시 `i-3`번째 계단에서 2칸 점프해서 왔어야 한다**는 것입니다.
(만약 `i-2`에서 왔다면 `i-2` -> `i-1` -> `i`가 되어 3연속 밟기가 되기 때문)
* **점화식:** `dp[i-3] + score[i-1] + score[i]`

### 최종 점화식
위 두 경우 중 더 큰 값을 선택하면 됩니다.

`dp[i] = max(dp[i-2], dp[i-3] + score[i-1]) + score[i]`

## 코드 (C++)

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    cin >> n;

    // 계단 점수 입력 (인덱스 1부터 사용)
    vector<int> score(n + 1);
    vector<int> dp(n + 1);

    for (int i = 1; i <= n; i++) {
        cin >> score[i];
    }

    // 초기값 설정 (Base Case)
    dp[1] = score[1];
    if (n >= 2) dp[2] = score[1] + score[2];
    if (n >= 3) dp[3] = max(score[1] + score[3], score[2] + score[3]);

    // 점화식 적용 (Bottom-Up)
    for (int i = 4; i <= n; i++) {
        dp[i] = max(dp[i - 2], dp[i - 3] + score[i - 1]) + score[i];
    }

    cout << dp[n] << "\n";

    return 0;
}
```
