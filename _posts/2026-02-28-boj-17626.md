## 문제 링크
[https://www.acmicpc.net/problem/17626](https://www.acmicpc.net/problem/17626)

## 문제 설명
정수 n이 주어졌을 때, n을 제곱수들의 합으로 표현할 수 있다.
이때 필요한 제곱수 항의 최소 개수를 출력한다.

---

## 풀이 전략
이 문제는 전형적인 **Dynamic Programming(DP)** 최솟값 문제입니다.

### 1. 상태 정의 및 점화식 도출
`dp[i]`를 정수 i를 제곱수들의 합으로 나타낼 때 필요한 항의 최소 개수라고 정의하면,

i를 만들기 위해 마지막에 어떤 제곱수 `j^2`를 하나 사용한다고 생각할 수 있습니다.
그러면 남는 값은 `i - j^2` 이고, 여기에 `j^2` 한 개를 추가한 것이므로

- 후보: `dp[i - j^2] + 1`

이 후보들 중 최솟값이 `dp[i]` 입니다.

$$
dp[i] = \min_{1 \le j^2 \le i}\big(dp[i - j^2] + 1\big)
$$

기저 조건은 다음과 같습니다.

$$
dp[0]=0
$$

(0은 아무 제곱수도 사용하지 않으면 되므로 0개)

---

## 코드 (C++)
#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>

using namespace std;

int n;
vector<int> dp;

void init()
{
    cin >> n;
    dp.assign(n + 1, INT_MAX);
    dp[0] = 0;
}

void solve()
{
    init();

    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j * j <= i; j++)
        {
            int num = i - j * j;
            dp[i] = min(dp[i], dp[num] + 1);
        }
    }

    cout << dp[n];
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}

## 복잡도 분석
### 1. 시간복잡도 : $$O(N\sqrt{N})$$
각 i(1~N)에 대해 j를 1부터 $$\sqrt{i}$$ 까지 확인합니다.
따라서 전체 반복은 대략 $$\sum_{i=1}^{N}\sqrt{i} \approx O(N\sqrt{N})$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
dp 배열이 크기 N+1로 필요하므로 $$O(N)$$ 공간을 사용합니다.
