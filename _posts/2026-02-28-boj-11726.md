## 문제 링크
[https://www.acmicpc.net/problem/11726](https://www.acmicpc.net/problem/11726)

## 문제 설명
2×n 크기의 직사각형을 1×2, 2×1 타일로 채우는 방법의 수를 구하는 프로그램을 작성하시오. 
결과는 10,007로 나눈 나머지를 출력해야 합니다.

---

## 풀이 전략 (Approach)

이 문제는 전형적인 **Dynamic Programming(DP)** 문제입니다. 큰 문제를 작은 문제의 결합으로 쪼개어 생각하면 점화식을 쉽게 도출할 수 있습니다.

### 1. 상태 정의 및 점화식 도출
`dp[i]`를 2×i 크기의 직사각형을 채우는 방법의 수라고 정의했을 때, 마지막 부분을 채우는 방법은 두 가지입니다.



1. **2×1 타일 1개를 세로로 붙이는 경우**: 나머지 공간은 2×(i-1) 크기가 되며, 경우의 수는 `dp[i-1]`입니다.
2. **1×2 타일 2개를 가로로 눕혀 붙이는 경우**: 나머지 공간은 2×(i-2) 크기가 되며, 경우의 수는 `dp[i-2]`입니다.

### 2. 최종 점화식
$$
dp[i] = (dp[i-1] + dp[i-2]) \pmod{10007}
$$

## 코드 (C++)

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    // n+1 크기로 할당하여 인덱스 에러 방지
    vector<int> dp(n + 1, 0);

    // 초기값 설정 (Base Case)
    if (n >= 1) dp[1] = 1;
    if (n >= 2) dp[2] = 2;

    // 점화식 적용 (Bottom-Up)
    for (int i = 3; i <= n; i++) {
        // 연산 과정에서 매번 나머지 연산을 수행하여 오버플로우 방지
        dp[i] = (dp[i - 1] + dp[i - 2]) % 10007;
    }

    // 최종 결과 출력
    cout << dp[n] << "\n";
    
    return 0;
}
```
