## 문제 링크
[https://www.acmicpc.net/problem/11726](https://www.acmicpc.net/problem/11726)

## 문제 설명
2×n 크기의 직사각형을 1×2, 2×1 타일로 채우는 방법의 수를 구하는 프로그램을 작성하시오.  
결과는 10,007로 나눈 나머지를 출력해야 합니다.

---

## 풀이 전략 (Approach)
이 문제는 전형적인 **Dynamic Programming(DP)** 문제입니다.

### 1. 상태 정의 및 점화식 도출
`dp[i]`를 2×i 크기의 직사각형을 채우는 방법의 수라고 정의하면,

- 세로로 2×1 하나: `dp[i-1]`
- 가로로 1×2 두 개: `dp[i-2]`

따라서,

$$
dp[i] = (dp[i-1] + dp[i-2]) \pmod{10007}
$$

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> dp(n + 1, 0);

    if (n >= 1) dp[1] = 1;
    if (n >= 2) dp[2] = 2;

    for (int i = 3; i <= n; i++) {
        dp[i] = (dp[i - 1] + dp[i - 2]) % 10007;
    }

    cout << dp[n] << "\n";
    return 0;
}
```
