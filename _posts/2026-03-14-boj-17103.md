## 문제 링크
[https://www.acmicpc.net/problem/17103](https://www.acmicpc.net/problem/17103)

## 문제 설명
짝수 N(4 ≤ N ≤ 1,000,000)이 주어졌을 때,
N = A + B 를 만족하는 두 소수 A, B의 쌍의 개수(골드바흐 파티션)를 구한다.

- (A, B)와 (B, A)는 같은 파티션으로 취급한다.
- 즉, A ≤ B인 경우만 센다.

여러 테스트 케이스에 대해 각 N의 파티션 개수를 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 소수 판별을 빠르게 해야 하므로, 먼저 1,000,000까지의 소수를 전부 구한 뒤
각 N에 대해 가능한 A를 절반까지만 확인하는 방식으로 해결합니다.

### 1. 상태 정의 및 알고리즘 도출
- `prime[x]`를 x가 소수인지 여부(true/false)로 정의한다.
- 에라토스테네스의 체로 2부터 1,000,000까지 소수 여부를 미리 계산한다.

각 테스트 케이스 N에 대해:
- A를 2부터 N/2까지 순회한다. (A ≤ B 조건을 자동으로 만족)
- `prime[A]`이고 `prime[N-A]`이면 한 가지 파티션이므로 카운트를 증가시킨다.
- 최종 카운트를 출력한다.

## 코드 (C++)
```cpp
#include <iostream>
using namespace std;

const int MAX = 1000000;

int t, n;
bool prime[MAX + 1];

void init() {
    for (int i = 0; i <= MAX; i++) prime[i] = true;
    prime[0] = prime[1] = false;

    for (int i = 2; i * i <= MAX; i++) {
        if (!prime[i]) continue;
        for (int j = i * i; j <= MAX; j += i) {
            prime[j] = false;
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();

    cin >> t;
    while (t--) {
        cin >> n;

        int cnt = 0;
        for (int i = 2; i <= n / 2; i++) {
            if (prime[i] && prime[n - i]) cnt++;
        }

        cout << cnt << '\n';
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(MAX \log \log MAX + \sum_{case} N)$$
- 에라토스테네스의 체: $$O(MAX \log \log MAX)$$
- 각 테스트 케이스마다 i를 2부터 N/2까지 확인하므로 $$O(N)$$ 수준입니다.
따라서 전체는 “체 전처리 + 각 케이스의 선형 검사”로 위와 같습니다.

### 2. 공간복잡도 : $$O(MAX)$$
소수 여부를 저장하는 `prime` 배열이 크기 MAX+1이므로 $$O(MAX)$$ 공간이 필요합니다.
