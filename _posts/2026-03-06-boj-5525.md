## 문제 링크
[https://www.acmicpc.net/problem/5525](https://www.acmicpc.net/problem/5525)

## 문제 설명
N이 주어졌을 때, 패턴 Pn은 다음과 같다.

- Pn = I(OI)^N  (길이: 2N+1)

길이 M의 문자열 S 안에 Pn이 몇 번 포함되어 있는지 출력한다.
(겹쳐서 포함되는 것도 센다)

---

## 풀이 전략 (Approach)
이 문제는 문자열에서 "IOI" 반복 패턴을 연속으로 몇 번 만들 수 있는지 세어,
Pn이 성립하는 순간마다 카운트를 증가시키는 방식으로 해결하는 **문자열 패턴 탐색** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
- `cnt` : 현재 위치까지 연속으로 발견한 "IOI" 패턴의 개수
- "IOI"가 한 번 나오면 cnt를 1 증가시킨다.
- "IOI"가 연속으로 이어지면 `cnt`가 계속 누적된다.
- `cnt >= N`이 되는 순간부터는 Pn이 성립하므로 그때마다 정답(ans)을 1 증가시킨다.
  - 예: N=2면 "IOIOI"가 필요하고, "IOIOIOI" 안에는 겹치는 "IOIOI"가 2개 있으므로 cnt가 커질수록 ans가 계속 증가한다.
- 패턴을 발견했을 때 i를 한 칸 더 증가시키면(코드에서 i++) 다음 검사 위치를 효율적으로 이동할 수 있다.
- 패턴이 끊기면 `cnt = 0`으로 초기화한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <string>
using namespace std;

int n, m;
string s;
int ans, cnt;

void init()
{
    cin >> n >> m >> s;
    ans = 0;
    cnt = 0;
}

void solve()
{
    init();

    for (int i = 1; i < m - 1; i++)
    {
        if (s[i - 1] == 'I' && s[i] == 'O' && s[i + 1] == 'I')
        {
            cnt++;
            if (cnt >= n) ans++;
            i++;
        }
        else
        {
            cnt = 0;
        }
    }

    cout << ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(M)$$
문자열을 한 번 순회하면서 조건 검사만 수행합니다.
패턴을 찾았을 때 i를 추가로 1 증가시키지만, 전체적으로 각 인덱스는 상수 번만 처리되므로
전체 시간은 문자열 길이 M에 비례합니다.
따라서 시간복잡도는 $$O(M)$$ 입니다.

### 2. 공간복잡도 : $$O(1)$$
추가로 사용하는 변수는 상수 개수(ans, cnt 등)이며,
입력 문자열 S만 저장하므로 부가 공간은 $$O(1)$$ 입니다.
