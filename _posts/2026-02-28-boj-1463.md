## 문제 링크
[https://www.acmicpc.net/problem/1463](https://www.acmicpc.net/problem/1463)

## 문제 설명
정수 N이 주어졌을 때, 아래 연산을 사용해서 N을 1로 만들려고 한다. 연산을 사용하는 횟수의 최솟값을 출력한다.

- N이 3으로 나누어떨어지면, 3으로 나눈다.
- N이 2로 나누어떨어지면, 2로 나눈다.
- 1을 뺀다.

---

## 풀이 전략 (Approach)
이 문제는 전형적인 **Dynamic Programming(DP)** 최소 연산 횟수 문제입니다.

### 1. 상태 정의
`dp[i]`를 정수 i를 1로 만드는 데 필요한 최소 연산 횟수라고 정의합니다.

### 2. 점화식 도출
정수 i에서 가능한 이전 상태는 다음 3가지입니다.

- i에서 1을 뺀 경우: `dp[i-1] + 1`
- i가 2로 나누어떨어질 때: `dp[i/2] + 1`
- i가 3으로 나누어떨어질 때: `dp[i/3] + 1`

따라서,

$$
dp[i] = \min\Big(dp[i-1] + 1,\; dp[i/2] + 1 \ (i\%2=0),\; dp[i/3] + 1 \ (i\%3=0)\Big)
$$

---

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main()
{
    int n;
    cin >> n;
    vector<int> dp(n + 1, 0);

    dp[0] = 0;
    dp[1] = 0;

    for (int i = 2; i <= n; i++)
    {
        dp[i] = dp[i - 1] + 1;
        if (i % 3 == 0)
            dp[i] = min(dp[i], dp[i / 3] + 1);
        if (i % 2 == 0)
            dp[i] = min(dp[i], dp[i / 2] + 1);
    }

    cout << dp[n];

    return 0;
}
```

---

## 코드 리뷰 (Review)
### 1) 점화식 구현이 정확함
- dp[i]를 먼저 `dp[i-1] + 1`로 초기화한 뒤,
- i가 3 또는 2로 나누어떨어질 때 더 작은 값으로 갱신하는 방식이 깔끔합니다.
- “가능한 연산 중 최소”를 취하는 형태라 논리적으로 정확합니다.

### 2) 초기값 설정에 대한 코멘트
- `dp[1]=0`은 필수입니다. 1은 이미 1이므로 연산 0회가 맞습니다.
- `dp[0]=0`은 이 문제에서 직접 참조되진 않아서 없어도 동작하지만, 넣어둬도 문제 없습니다.
- 단, N의 입력 범위가 1 이상이라면 dp[0]은 의미상 “사용하지 않는 값” 정도로만 생각하면 됩니다.

### 3) 출력 형식
- `cout << dp[n];` 뒤에 개행이 없어도 통과는 되지만, 습관적으로 `"\n"`을 붙이면 좋습니다.

### 4) 최적화(선택)
- dp는 `int dp[1000001];` 같은 배열로도 충분합니다.
- vector도 충분히 빠르고 안전합니다(이 문제 범위에서 성능 문제 없음).

## 복잡도 분석
### 1. 시간복잡도 : $$O(N)$$
i를 2부터 N까지 한 번씩만 계산합니다.

### 2. 공간복잡도 : $$O(N)$$
dp 배열(또는 vector)에 1부터 N까지 저장합니다.
