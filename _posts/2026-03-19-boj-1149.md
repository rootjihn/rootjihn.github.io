## 문제 링크
[https://www.acmicpc.net/problem/1149](https://www.acmicpc.net/problem/1149)

## 문제 설명
N개의 집이 일렬로 있고, 각 집을 빨강/초록/파랑 중 하나로 칠할 때의 비용이 주어진다.
인접한 두 집은 같은 색으로 칠할 수 없을 때, 모든 집을 칠하는 최소 비용을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “i번째 집을 특정 색으로 칠했을 때의 최소 누적 비용”을 상태로 잡으면,
바로 이전 집의 색만 고려해서 갱신할 수 있는 전형적인 **Dynamic Programming(DP)** 문제입니다.

### 1. 상태 정의 및 점화식 도출
`dp[i][c]`를 “i번째 집을 색 c로 칠했을 때, 1~i번째 집까지 칠하는 최소 비용”이라고 정의합니다.
(c는 0=R, 1=G, 2=B)

인접한 집은 같은 색이 불가능하므로, i번째 집을 c로 칠하려면 (i-1)번째 집은 c가 아닌 색이어야 합니다.

따라서 점화식은 다음과 같습니다.

- R로 칠하는 경우:
  - 이전 집은 G 또는 B
  - `dp[i][0] = cost[i][0] + min(dp[i-1][1], dp[i-1][2])`

- G로 칠하는 경우:
  - 이전 집은 R 또는 B
  - `dp[i][1] = cost[i][1] + min(dp[i-1][0], dp[i-1][2])`

- B로 칠하는 경우:
  - 이전 집은 R 또는 G
  - `dp[i][2] = cost[i][2] + min(dp[i-1][0], dp[i-1][1])`

기저 조건:
- `dp[1][c] = cost[1][c]`

정답:
- `min(dp[n][0], dp[n][1], dp[n][2])`

## 코드 (C++)
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int n;
int cost[1001][3];
int dp[1001][3];

void init()
{
    cin >> n;

    for (int i = 1; i <= n; i++)
    {
        cin >> cost[i][0] >> cost[i][1] >> cost[i][2];
    }
}

void solve()
{
    dp[1][0] = cost[1][0];
    dp[1][1] = cost[1][1];
    dp[1][2] = cost[1][2];

    for (int i = 2; i <= n; i++)
    {
        dp[i][0] = cost[i][0] + min(dp[i - 1][1], dp[i - 1][2]);
        dp[i][1] = cost[i][1] + min(dp[i - 1][0], dp[i - 1][2]);
        dp[i][2] = cost[i][2] + min(dp[i - 1][0], dp[i - 1][1]);
    }

    cout << min({dp[n][0], dp[n][1], dp[n][2]});
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N)$$
각 집 i(2~N)에 대해 3가지 색 상태를 상수 시간으로 갱신합니다.
따라서 시간복잡도는 $$O(N)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
cost와 dp 배열이 각각 크기 N×3이므로 $$O(N)$$ 공간을 사용합니다.
