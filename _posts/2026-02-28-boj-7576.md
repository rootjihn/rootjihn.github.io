## 문제 링크
[https://www.acmicpc.net/problem/7576](https://www.acmicpc.net/problem/7576)

## 문제 설명
N×M 크기의 상자에 토마토가 들어있다.

- 1: 익은 토마토
- 0: 익지 않은 토마토
- -1: 토마토가 들어있지 않은 칸

하루가 지나면 익은 토마토의 인접한(상하좌우) 익지 않은 토마토가 익는다.
모든 토마토가 익기까지 필요한 최소 일수를 출력하고, 처음부터 모두 익어있다면 0, 끝까지 모두 익지 못하면 -1을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 여러 시작점에서 동시에 퍼져나가는 형태이므로 **그래프 탐색(BFS)** 로 해결하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`box[y][x]`를 (y, x) 칸의 상태라고 두면,

- 처음에 값이 1인 칸들(이미 익은 토마토)을 모두 큐에 넣고 BFS를 시작한다. (멀티 소스 BFS)
- BFS로 전파될 때, 익지 않은 토마토(0)를 만나면 큐에 넣고 “익은 날짜”를 갱신한다.
- `box[ny][nx] = box[cp.y][cp.x] + 1` 로 저장하면, 해당 칸이 몇 번째 날에 익었는지(거리)가 기록된다.
- BFS가 끝난 뒤에도 0이 남아있으면, 도달하지 못한 칸이므로 -1이다.
- 0이 없다면, 가장 큰 값이 “마지막으로 익은 날”이므로 정답은 (최대값 - 1) 이다. (처음 익은 칸이 1로 시작했기 때문)

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

struct Point
{
    int y, x;
};

int dy[4] = { -1,1,0,0 };
int dx[4] = { 0,0,-1,1 };

int n, m;
int day = 0;
vector<vector<int>> box;

void bfs(queue<Point>& q)
{
    while (!q.empty())
    {
        Point cp = q.front();
        q.pop();

        for (int i = 0; i < 4; i++)
        {
            int ny = cp.y + dy[i];
            int nx = cp.x + dx[i];

            if (ny < 0 || nx < 0 || ny >= n || nx >= m)
                continue;

            if (box[ny][nx] == 0)
            {
                q.push({ ny,nx });
                box[ny][nx] = box[cp.y][cp.x] + 1;
            }
        }
    }
}

void init()
{
    cin >> m >> n;
    box.assign(n, vector<int>(m, 0));
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> box[i][j];
        }
    }
}

void solve()
{
    bool flag = true;
    queue<Point> q;

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (box[i][j] == 1)
                q.push({ i,j });
        }
    }

    bfs(q);

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            if (box[i][j] == 0)
                flag = false;

            if (day < box[i][j])
                day = box[i][j];
        }
    }

    if (flag) {
        cout << (day == 0 ? 0 : day - 1);
    }
    else {
        cout << -1;
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \times M)$$
각 칸은 BFS에서 최대 한 번 큐에 들어가며(익지 않은 칸이 익는 순간 0 → 양수로 바뀌어 재방문이 없음),
각 칸에서 상하좌우 4방향만 확인하므로 전체 연산은 칸 수에 비례합니다.
따라서 시간복잡도는 $$O(NM)$$ 입니다.

### 2. 공간복잡도 : $$O(N \times M)$$
상자 정보 `box`가 $$O(NM)$$ 이고,
최악의 경우 큐에도 거의 모든 칸이 들어갈 수 있어 $$O(NM)$$ 공간이 추가로 필요할 수 있습니다.
따라서 공간복잡도는 $$O(NM)$$ 입니다.
