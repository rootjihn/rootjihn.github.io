## 문제 링크
[https://www.acmicpc.net/problem/11286](https://www.acmicpc.net/problem/11286)

## 문제 설명
절댓값 힙은 다음과 같은 연산을 지원하는 자료구조이다.

- 배열에 정수 x(x ≠ 0)를 넣는다.
- x가 0이라면 배열에서 절댓값이 가장 작은 값을 출력하고 그 값을 배열에서 제거한다.
  - 절댓값이 가장 작은 값이 여러 개일 경우, 그 중에서 “가장 작은 수(음수 우선)”를 출력한다.
  - 배열이 비어있는데 0이 들어오면 0을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “절댓값이 작은 값 우선, 절댓값이 같으면 실제 값이 작은 것(음수 우선)” 정렬 기준을 가진 힙이 필요하므로
**우선순위 큐 + 커스텀 비교자**로 해결하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
우선순위 큐에 넣을 원소를 다음 정보로 관리합니다.

- `x` : 절댓값 `abs(value)`
- `sign` : 부호 정보 (양수면 true, 음수면 false)

정렬 기준(compare)
- 절댓값 `x`가 작은 것이 우선
- 절댓값이 같으면 음수가 우선(즉, 실제 값이 더 작은 것이 우선)

입력 처리
- 입력이 0이 아니면 우선순위 큐에 (abs, sign)을 push 한다.
- 입력이 0이면:
  - 큐가 비었으면 0 출력
  - 비어있지 않으면 top을 꺼내서 sign에 따라 ±를 붙여 출력한다.

## 코드 (C++)
```cpp
#include <iostream>
#include <queue>
#include <cmath>
#include <vector>

using namespace std;

struct Num
{
    int x;
    bool sign;
};

struct compare
{
    bool operator()(const Num &a, const Num &b)
    {
        if (a.x != b.x)
            return a.x > b.x;

        return a.sign > b.sign;
    }
};

int n;
vector<int> cal;
priority_queue<Num, vector<Num>, compare> pq;

void init()
{
    cin >> n;
    cal.assign(n, 0);
}

void solve()
{
    init();

    for (int i = 0; i < n; ++i)
    {
        bool tmp;
        cin >> cal[i];
        cal[i] >= 0 ? tmp = true : tmp = false;

        if (cal[i] != 0)
            pq.push({abs(cal[i]), tmp});
        else
        {
            if(pq.empty())
            {
                cout << 0 << "\n";
                continue;
            }

            Num result = pq.top();
            pq.pop();

            if(result.sign)
                cout << result.x << "\n";
            else
                cout << -result.x << "\n";
        }
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \log N)$$
총 N번의 연산이 들어오며,
0이 아닌 입력은 push, 0인 입력은 pop이 발생할 수 있습니다.
힙 연산(push/pop)은 한 번에 $$O(\log S)$$ (S는 힙 크기) 이고 최악의 경우 S가 N까지 커질 수 있으므로
전체 시간복잡도는 $$O(N \log N)$$ 수준입니다.

### 2. 공간복잡도 : $$O(N)$$
우선순위 큐에 입력된 값들이 저장될 수 있으므로, 최악의 경우 $$O(N)$$ 공간이 필요합니다.
