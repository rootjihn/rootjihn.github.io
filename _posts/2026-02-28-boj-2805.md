## 문제 링크
https://www.acmicpc.net/problem/2805

## 문제 설명
N개의 나무가 있고 각 나무의 높이가 주어진다.
절단기의 높이를 H로 지정하면, 높이가 H보다 큰 나무는 H 위의 부분이 잘리고 그 길이만큼 나무를 가져간다.
가져갈 나무의 총 길이가 최소 M이 되도록 하는 절단기 높이 H의 최댓값을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 “조건을 만족하는 H 중 최댓값”을 찾는 형태이므로 **이분 탐색(파라메트릭 서치)** 으로 해결하는 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
절단기 높이를 H라고 할 때, H로 잘랐을 때 얻는 나무 총합을 `total(H)`라고 하면,

- H가 커질수록 잘리는 양은 줄어들어 `total(H)`는 단조 감소한다.
- 즉, `total(H) >= M`을 만족하는 H의 구간이 연속적으로 존재하므로 이분 탐색이 가능하다.

이분 탐색 범위는 다음과 같이 잡는다.
- `left = 0`
- `right = max_h` (입력 나무 중 최대 높이)

중간값 `mid`에 대해:
- `total(mid) >= M` 이면 조건을 만족하므로 더 큰 H를 시도하기 위해 `left = mid + 1`, 정답 후보 `result = mid` 갱신
- `total(mid) < M` 이면 부족하므로 H를 낮추기 위해 `right = mid - 1`

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long m;
    cin >> n >> m;

    vector<long long> tree(n);
    long long max_h = 0;

    for (int i = 0; i < n; i++)
    {
        cin >> tree[i];
        if (tree[i] > max_h)
        {
            max_h = tree[i];
        }
    }

    long long left = 0;
    long long right = max_h;
    long long result = 0;

    while (left <= right)
    {
        long long mid = left + (right - left) / 2;
        long long total = 0;

        for (int i = 0; i < n; i++)
        {
            if (tree[i] > mid)
            {
                total += (tree[i] - mid);
            }
        }

        if (total >= m)
        {
            result = mid;
            left = mid + 1;
        }
        else
        {
            right = mid - 1;
        }
    }

    cout << result << "\n";

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N \log H)$$
이분 탐색은 높이 범위(0 ~ max_h)에서 진행되므로 반복 횟수가 $$O(\log H)$$ 입니다. (여기서 $$H = max\_h$$)
각 반복마다 모든 나무를 순회하며 `total`을 계산하므로 $$O(N)$$ 이 걸립니다.
따라서 전체 시간복잡도는 $$O(N \log H)$$ 입니다.

### 2. 공간복잡도 : $$O(N)$$
나무 높이를 저장하는 배열 `tree`가 $$O(N)$$ 공간을 사용하며,
그 외 변수들은 상수 공간이므로 전체 공간복잡도는 $$O(N)$$ 입니다.
