## 문제 링크
[https://www.acmicpc.net/problem/1932](https://www.acmicpc.net/problem/1932)

## 문제 설명
정수 삼각형이 주어졌을 때, 꼭대기에서 시작하여 아래층으로 내려가며 선택한 수들의 합이 최대가 되는 경로의 합을 구한다.
아래층으로 내려갈 때는 바로 아래 또는 오른쪽 아래로만 이동할 수 있다.

---

## 풀이 전략 (Approach)
이 문제는 각 위치까지 도달했을 때의 “최대 누적 합”을 저장하며 아래로 내려가는 전형적인 **Dynamic Programming(DP)** 문제입니다.

### 1. 상태 정의 및 점화식 도출
`dp[i][j]`를 i번째 줄(0-index)에서 j번째 원소까지 내려왔을 때 만들 수 있는 최대 합이라고 정의하면,

- 왼쪽 끝(j=0)은 위에서 내려올 수 있는 경로가 하나뿐:
  - `dp[i][0] = dp[i-1][0] + tree[i][0]`
- 오른쪽 끝(j=i)도 위에서 내려올 수 있는 경로가 하나뿐:
  - `dp[i][i] = dp[i-1][i-1] + tree[i][i]`
- 그 외 위치(0<j<i)는 위의 두 위치 중 큰 값을 선택:
  - `dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + tree[i][j]`

기저 조건:
- `dp[0][0] = tree[0][0]`

정답:
- 마지막 줄의 `dp[n-1][j]` 중 최댓값

## 코드 (C++)
```cpp
#include <iostream>
#include <algorithm>
#include <vector>
#include <climits>

using namespace std;

int n;
int nodeNum;
int ans = INT_MIN;
vector<vector<int>> tree;
vector<vector<int>> dp;

void init()
{
    cin >> n;
    tree.assign(n, vector<int>());
    dp.assign(n, vector<int>());

    for (int i = 0; i < n; ++i)
    {
        tree[i].resize(i + 1, 0);
        dp[i].resize(i + 1, 0);

        for (int j = 0; j <= i; ++j)
        {
            cin >> tree[i][j];
        }
    }
}

void solve()
{
    init();

    dp[0][0] = tree[0][0];

    for (int i = 1; i < n; ++i)
    {
        for (int j = 0; j <= i; ++j)
        {
            if (j == 0)
            {
                dp[i][j] = dp[i - 1][j] + tree[i][j];
            }
            else if (j == i)
            {
                dp[i][j] = dp[i - 1][j - 1] + tree[i][j];
            }
            else
            {
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - 1]) + tree[i][j];
            }
        }
    }

    for (int i = 0; i < n; ++i)
    {
        ans = max(ans, dp[n - 1][i]);
    }

    cout << ans;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N^2)$$
삼각형의 원소 개수는 1 + 2 + ... + N = $$O(N^2)$$ 입니다.
각 원소에 대해 dp를 한 번씩 계산하므로 전체 시간복잡도는 $$O(N^2)$$ 입니다.

### 2. 공간복잡도 : $$O(N^2)$$
삼각형 입력 `tree`와 dp 배열 `dp`가 각각 $$O(N^2)$$ 공간을 사용합니다.
