## 문제 링크
https://www.acmicpc.net/problem/1697

## 문제 설명
수빈이는 현재 점 N에 있고, 동생은 점 K에 있다. 수빈이는 아래 3가지 방법으로 이동할 수 있다.

- X-1로 이동
- X+1로 이동
- 2*X로 이동

수빈이가 동생을 찾는 가장 빠른 시간을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 1차원 좌표에서 최단 시간을 구하는 전형적인 **그래프 탐색(BFS)** 문제입니다.

### 1. 상태 정의 및 알고리즘 도출
`visited[x]`를 좌표 x에 도달하는 데 걸린 시간을 저장하는 배열이라고 정의하면,

- 시작점 N에서 BFS를 시작한다.
- 간선(이동)은 모두 비용이 1이므로, BFS의 레벨 순회가 곧 최단 시간이다.
- 한 위치 x에서 다음 위치는 `x-1`, `x+1`, `2*x` 세 가지이며, 범위(0 ~ 100000) 안에서만 이동한다.
- 아직 방문하지 않은 위치만 큐에 넣어 중복 탐색을 막는다.
- 목표 위치 K에 도달했을 때의 시간이 정답이다.

## 코드 (C++)
```cpp
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

int n, k;
vector<int> visited(100001, 0);

int bfs()
{
    queue<int> q;
    q.push(n);
    visited[n] = 1;

    while (!q.empty())
    {
        int now = q.front();
        q.pop();

        if (now == k)
            break;

        int sub_pos = now - 1;
        int plus_pos = now + 1;
        int mul_pos = 2 * now;

        if (sub_pos >= 0 && visited[sub_pos] == 0)
        {
            q.push(sub_pos);
            visited[sub_pos] = visited[now] + 1;
        }

        if (plus_pos < 100001 && visited[plus_pos] == 0)
        {
            q.push(plus_pos);
            visited[plus_pos] = visited[now] + 1;
        }

        if (mul_pos < 100001 && visited[mul_pos] == 0)
        {
            q.push(mul_pos);
            visited[mul_pos] = visited[now] + 1;
        }
    }

    return visited[k] - 1;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> k;
    cout << bfs();

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(100000)$$
좌표는 0부터 100000까지로 최대 100001개이며,
BFS에서 각 좌표는 방문 처리 후 최대 한 번만 큐에 들어갑니다.
각 좌표에서 확인하는 이동은 최대 3가지이므로 전체 시간은 방문 가능한 정점 수에 비례합니다.
따라서 시간복잡도는 $$O(100000)$$ 수준(정확히는 $$O(V+E)$$에서 V≈100001, E≈3V)입니다.

### 2. 공간복잡도 : $$O(100000)$$
`visited` 배열이 100001 크기이고,
큐에도 최악의 경우 많은 좌표가 들어갈 수 있으므로 $$O(100000)$$ 공간이 필요합니다.
