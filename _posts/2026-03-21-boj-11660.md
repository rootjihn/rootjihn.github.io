## 문제 링크
[https://www.acmicpc.net/problem/11660](https://www.acmicpc.net/problem/11660)

## 문제 설명
N×N 표에 수가 채워져 있고, M개의 질의가 주어진다.
각 질의마다 (x1, y1)부터 (x2, y2)까지의 합을 출력한다.

---

## 풀이 전략 (Approach)
이 문제는 2차원 구간 합을 빠르게 처리하기 위해 **2차원 누적 합(Prefix Sum)** 을 사용하는 문제입니다.
누적 합을 미리 만들어두면 각 질의를 O(1)에 처리할 수 있습니다.

### 1. 상태 정의 및 점화식 도출
`sum[i][j]`를 (1,1)부터 (i,j)까지의 누적 합이라고 정의하면,

현재 칸까지의 누적 합은
- 위쪽 누적 합 `sum[i-1][j]`
- 왼쪽 누적 합 `sum[i][j-1]`
을 더하고,
겹쳐서 두 번 더해진 좌상단 영역 `sum[i-1][j-1]`을 한 번 빼준 뒤,
현재 값 `arr[i][j]`를 더하면 됩니다.

$$
sum[i][j] = arr[i][j] + sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1]
$$

질의 (x1, y1) ~ (x2, y2)의 합은 포함-배제 원리로 다음과 같이 구합니다.

$$
ans = sum[x2][y2] - sum[x1-1][y2] - sum[x2][y1-1] + sum[x1-1][y1-1]
$$

## 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<vector<int>> arr(n + 1, vector<int>(n + 1, 0));
    vector<vector<int>> sum(n + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            cin >> arr[i][j];
            sum[i][j] = arr[i][j]
                      + sum[i - 1][j]
                      + sum[i][j - 1]
                      - sum[i - 1][j - 1];
        }
    }

    while (m--)
    {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;

        int ans = sum[x2][y2]
                - sum[x1 - 1][y2]
                - sum[x2][y1 - 1]
                + sum[x1 - 1][y1 - 1];

        cout << ans << '\n';
    }

    return 0;
}
```

## 복잡도 분석
### 1. 시간복잡도 : $$O(N^2 + M)$$
누적 합 배열을 만드는 데 $$O(N^2)$$,
각 질의는 포함-배제로 $$O(1)$$ 이므로 M개 질의 처리에 $$O(M)$$ 입니다.
따라서 전체 시간복잡도는 $$O(N^2 + M)$$ 입니다.

### 2. 공간복잡도 : $$O(N^2)$$
입력 배열 `arr`와 누적 합 배열 `sum`이 각각 $$O(N^2)$$ 공간을 사용합니다.
